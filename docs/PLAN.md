## 5. 首次学习流程（概要，细则由 T11 写进 skill）

1. 在主 checkout 打开 Claude Code，说「开始学 Python 第 1 级」或「开始学 P1 第 1 章」。
2. AI 读 skill、对应记录表与最新交接文档，一行报告模式与位置。
3. 理论题型：概念速览（英文 MS 句 / 中文 / 直观理解）→ 代表题精讲（原卷页 + MS 逐分点）→ 学生做变式 → 批改 + 记录 + 讲下一型 + 布置变式（一条回复完成）。
4. 编程题型：题型卡 → 代表题精讲 → 练习文件夹 → 学生在 VS Code 写（P2 先伪代码再 Python）→ 「测一下」：pytest + MS 得分点逐条核对 → 记录。
5. 每条教学回复末尾 📌 学习锚点；停下时说「交接」生成交接文档。
