## 2. 设计思路

### 2.1 考场作答方法：把“MS 怎样给分”翻成“90 分钟怎样花”

卷首已有十条通用得分规则，书末已有得分链和命令词表，但都是“知识”；学生缺的是“流程”。每页按同一结构写：**时间**（用语料算出来：P1 每卷 6–11 题、最大题 12–22 分；P2 的 Q1–Q5 平均 42 分；P3 每卷 9–13 题、没有 20 分大题；P4 固定三道 20–34 分）→ **读题 30 秒圈什么** → **各类题的答案形状** → **会但丢分的十种写法**（每行给出“为什么丢”的证据：该题 MS 原句，或考官报告的说法）→ **交卷前的检查清单**。四页的“丢分表”是给学生自己续写的：每次模考把自己丢分的写法补进去。

### 2.2 教学 skill：先找缺的那一环，再把错误变成下一道题

原来的 few-shots 示范了“怎样讲”和“怎样批”，没有示范“怎样知道他是哪一环没想通”。加了两样东西：

- **六种探针**（机制、反事实、状态、边界、对比、反向）：一次只问一个，最多两个；得分按探针**之前**的作答判，探针后的改写只写进「解释证据」——不改 SKILL.md 的门槛（§6）、记录规则（§10）和 D47 协议。示例 6（缓冲区，w24/11 Q3(d)(ii)）用两个探针让学生自己推出“速度差”这一环；示例 7（追踪表，w23/23 Q5）用状态探针把“当前值看列底”这条规则交给他。
- **错误转成下一道题**：每个 ✗ 换成一道 30 秒的检索题，换情境问同一个模型，写进交接文档「待办 · 下次开场检索」；下次开场 2 分钟做 2–3 道，✗ 的只给 MS 句；**不改记录表**（检索不是复测，复测仍按 §4.5）；间隔 1 天 → 1 周 → 章末。示例 8 是一次完整的开场检索。

### 2.3 概念主线：同一样东西四张卷怎样问

三条线：数据组织（变量 → 数组 → 记录 → 栈 / 队列 → 链表 / 树 → 哈希 → 类 → 文件）、系统（P1 六章 → P3 六章的不变量与新增）、同一算法的三种写法（P2 伪代码 → P3 伪代码进阶 → P4 Python）。每一步只回答五个问题：新增了什么、什么没变、旧知识怎样搬、在哪里考（题型码）、最常想错什么。每条线末尾一张能**推出题型**的表——结构 × 动作（6 个动作 × 7 种结构，格子里是三卷的题型码）、理论题的四种问法、六处最易错的伪代码 → Python 翻译。这就是任务卡说的“把一章讲成一个能自己推出题型的模型”在跨卷层面的版本。

### 2.4 心智模型：章首从“题型清单”变成“能推出题型的图”

31 章的核心思想里大多数已经有模型句（DT 的“数据结构决定循环怎么写”、CT 的“指针就是下标”、SC 的“用谁的哪把钥匙”）。四章没有，补了：HW 的速度阶梯 + 感知—判断—执行环；SS 的资源管理员 + 翻译的时间点；CM 的“每个设备有地址、每一跳按地址转发”；EO 的三方关系图。每段结尾都说“看到一道题先定位到图的哪里”。

### 2.5 迁移与卡点：卡片原来缺的那一层

卡片原有“解题思路 / 易错 / 代表题 / 直观 / 变式”，但“直观”多是一句类比，“迁移”没有专门的位置，学生要自己猜代表题的解法有多少能搬到变式上。每块固定四条：

- **卡点**：学生最可能停住的那一步和解开它的一条规则（例：选循环只看“能不能提前结束”；追踪表当前值看列底；补码先取反加一再规格化；指针约定四件事一起变）。
- **考官在换什么**：这一型题与题之间变的维度，以及哪几分永远不变（骨架分）。
- **从代表题到变式**：什么能搬、什么要重写——只说要换的是什么，不解变式的答案（IR-03 用另一个数示范方法）。
- **反例**：一条取自该型考官报告或 MS 限定的具体错误写法。

## 3. 建议学生怎样用

1. **开学前**读 P1 的「考场作答方法」一页；每次模考前重读本卷那一页，模考后把自己丢分的写法补进第 5 节的表。
2. **每次换章**：先读 `docs/guide/概念主线.md` 里对应的那一步（1 月开 P3 前通读主线二，开 P4 前通读主线三），再读章首的核心思想（有「心智模型」的章先看它）。
3. **学一张 ★★★ 卡**：读完代表题精讲，先看「迁移与卡点」的前两条（卡点、考官在换什么），做变式之前再看第三条——它告诉你要换的是什么，不告诉你答案。
4. **每次课开场**：导师会出 2–3 道上次丢分变成的 30 秒检索题，不看笔记用英文答；连续两次答对才从清单消失。
5. **4 月冲刺**：用主线末尾的三张表自测——结构 × 动作的每一格能不能默写模板；四种问法各能说出骨架和两个题型；六处翻译能不能不看书写对。
