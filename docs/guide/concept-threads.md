# 跨卷概念主线：同一样东西，四张卷怎样问

> 给学生的读物，不是题型卡。四卷手册按卷、按章拆开讲；这份主线把跨卷反复出现的几样东西连成三条线，说清每一步**新增了什么、什么没变、旧知识怎样搬过来、最容易在哪里想错**。每条线末尾有一张“从模型推出题型”的表——把它背下来，看到一道没见过的题也能说出它在考哪一格。给分仍只认每题自己的 MS；这里引用的行号（⟦ ⟧ 里的卷与小问）是入口，不是给分依据。

**什么时候读**：换章时读与新章有关的那一步（例如学 P2-DT 前读主线一的第 1–2 步）；1 月开始 P3 前通读主线二；开始 P4 前通读主线三；4 月冲刺时用三张“推出题型”的表做自测——每一格能不能不看书写出模板或得分句。

## 主线一　数据怎样组织：变量 → 数组 → 记录 → 栈 / 队列 → 链表 / 二叉树 → 哈希表 → 类 → 文件

这条线贯穿 P2（DT 章）、P3（DR、CT、FP 章）、P4（AR、SQ、LT、OP、FL 章），占三张卷将近一半的分。每一步只在上一步上**加一样东西**；把那一样东西说清楚，这一步的全部题型就都能推出来。

### 第 0 步　变量：一个盒子、一个名字、一种类型

所有后面的结构都是“很多盒子怎样编组”。盒子的三件事——名字、类型、当前值——在每一步都不变：`DECLARE Count : INTEGER` 到 P4 的 `Count = 0  # INTEGER` 都是同一件事。

### 第 1 步　数组：一排同类型的盒子，用下标选

| | 内容 |
|:--|:--|
| **新增** | 下标（index）：一个整数决定你在看哪个盒子；上下界；“未用元素”要用一个约定值（0、−1、999、""）标记 |
| **不变** | 每个盒子仍是一个变量：`Data[3]` 能做的事和 `Count` 一模一样 |
| **迁移** | “处理每一个”= 下标从下界数到上界的循环；“找一个”= 循环 + 比较 + 找到就停；二维数组只是“下标有两个” |
| **在哪里考** | P2-DT-03（声明与术语）、DT-05 / DT-06（一维、二维处理模块）；P4-AR-01 / AR-02（声明并存入）、AR-04 / AR-05（输出与统计）；P3-CT-02 / CT-03 的查找排序也在数组上做 |
| **最常想错** | ①把字符串当数组：P2 伪代码里字符串没有下标，只有 `MID` / `LEFT` / `RIGHT`（P2-PG-11）；P4 的 Python 里字符串反而可以 `s[i]`。②下标起点：伪代码真题全是 `[1:n]`，Python 是 0 起——P4 题目会直接写“The index of the first element is 0”，照题目的数用。③`[[0] * 4] * 3` 三行共用一个列表（P4-AR-02） |

### 第 2 步　记录：一组不同类型的盒子，用字段名选

| | 内容 |
|:--|:--|
| **新增** | 字段名代替下标：`Loan.OnLoan` 而不是 `Loan[3]`；`TYPE … ENDTYPE` 把一组字段登记成一种新类型 |
| **不变** | 每个字段仍是一个变量；记录数组 = 先用下标选哪条记录，再用点号选哪个字段：`Loan[Index].OnLoan` |
| **迁移** | 第 1 步的循环原封不动，只是循环里访问的东西从 `Data[Index]` 变成 `Loan[Index].Field`；“找某条记录”= 比较一个字段 |
| **在哪里考** | P2-DT-02（定义与字段访问）、DT-07（记录数组处理模块）；P3-DR-01（组合 / 非组合类型的分类）、DR-03（声明记录类型）、DR-04（记录变量赋值）；P4-AR-03（记录结构，Python 用类表示）、FL-02（读文件建记录） |
| **最常想错** | ①`Loan.OnLoan[Index]`——点号和下标的顺序反了。②P3 问“record 是 composite 还是 non-composite”：记录由别的类型拼成，所以是组合类型；枚举、指针是非组合。③P4 里“record”用 `class` 写，但题目没要求私有就不要加 `__`（P4-AR-03 与 OP-01 的分界） |

### 第 3 步　栈与队列：数组加上“指针变量”

| | 内容 |
|:--|:--|
| **新增** | 一两个整数变量（Top、Head、Tail）记住“下一次操作在哪个格子”；一套**约定**：指针指“最后一项”还是“下一个空位”、初值是 0 还是 −1；判满、判空的条件由约定推出 |
| **不变** | 底下还是一个数组；“指针”在这一步**只是数组下标**，不是内存地址 |
| **迁移** | 入栈 / 入队 = 判满 → 按约定移指针并存值（先移后存或先存后移，由约定定）→ 返回成功；出栈 / 出队 = 判空 → 取值 → 移指针 → 返回取出的值。栈与队列的全部区别：栈一个指针、队列两个；栈从同一端进出、队列一端进另一端出 |
| **在哪里考** | P2-DT-12（ADT 的概念与选择）、DT-13 / DT-14（在图上做操作）、DT-16（数组实现）；P3-CT-05（ADT 比较与互相实现）、CT-06 / CT-07（写 Push / Pop、Enqueue / Dequeue）、CT-11（递归用栈）、SY-10 至 SY-12（RPN 用栈求值）；P4-SQ-01 至 SQ-04。栈还会在 P1-PF-04 与 P3-HV-02 露面：中断时寄存器内容压进栈（⟦9618_s25_12:1(c)⟧、⟦9618_s24_31:11(b)⟧） |
| **最常想错** | ①把自己习惯的约定带进题目：P4 考官报告每年都提“题目给了初值就用这个初值”（P4-SQ 章首）。②线性队列写成循环队列——题目没说 circular 就不回绕。③判空只写 `Head = -1`，漏掉“存过又全部取完”。④以为栈里会放运算符：RPN 求值时运算符触发弹出，不进栈 |

### 第 4 步　链表与二叉树：指针从“+1”变成“下一个在哪”

| | 内容 |
|:--|:--|
| **新增** | 每个结点自带一个（链表）或两个（二叉树）指针字段，存“下一个结点的下标”；一个空闲表指针记住哪些格子没用；空指针用约定值（0 或 −1）表示“到头了” |
| **不变** | 真题里它们仍是**记录数组**：结点 = 记录（Data + 指针字段），指针仍是下标；遍历仍是循环，只是从 `Index ← Index + 1` 变成 `Current ← List[Current].Pointer` |
| **迁移** | 第 2 步的记录数组 + 第 3 步的指针变量 = 这一步；插入 = 从空闲表取一格、填数据、改两根指针；删除 = 改指针绕过它、把它还给空闲表；二叉树的查找 = 每一步按大小选左或右 |
| **在哪里考** | P2-DT-15（链表操作与状态）、DT-16（链表的数组实现）；P3-CT-08（链表）、CT-09（二叉树结点图、存储表与查找）；P4-LT-01 至 LT-04 |
| **最常想错** | ①“指针 = 内存地址”：这是 P3-DR-02 指针**类型**（`^`）的含义；CT / LT 里的指针是整数下标，两者不要混。②遍历条件依赖 `AND` 短路去读 `List[Current]`（D25）：先判 `Current <> 0`，再读。③删除后忘了把结点还给空闲表；插入后忘了改空闲表指针。④二叉树“中序遍历得到有序序列”只对二叉查找树成立 |

### 第 5 步　哈希表：下标由键算出来

| | 内容 |
|:--|:--|
| **新增** | 不再逐个找，也不靠指针走：对键做一次计算（常是 `Key MOD n`）直接得到下标；两个键算到同一格叫冲突，要有处理办法（顺延找下一格、溢出区、链） |
| **不变** | 底下还是一个数组（或记录数组）；查找 = 算出下标 → 比较键 → 不对就按冲突规则继续 |
| **迁移** | 随机文件就是“存在磁盘上的哈希表”：`Location ← Hash(Key)` 再 `SEEK` 到那一条记录（⟦9618_w23_31:8(a)⟧） |
| **在哪里考** | P3-DR-08（散列算法与冲突）、DR-06 / DR-07（随机文件的组织与存取）、FP-10（随机文件代码）；P4-LT-05 |
| **最常想错** | ①“散列函数去**找**记录”——它只是算出一个地址，找不找得到还要比较键。②和数字签名里的 hash（P1-SP-05、P3-SC-06）同名不同用：那里的散列是把整条消息压成摘要，用来验证完整性，不是算存储位置 |

### 第 6 步　类与对象：记录 + 只允许通过指定操作去碰它

| | 内容 |
|:--|:--|
| **新增** | 把“数据”和“允许对它做的操作”放进同一个声明；属性私有，外界只能经 getter / setter / 其他方法访问；构造方法在创建对象时把参数存进属性；继承让子类复用父类并可重写；一个类的属性可以是另一个类的对象数组（包含） |
| **不变** | 属性就是记录的字段；方法就是“第一个参数固定是这个对象”的过程或函数（`self`）；对象数组仍按第 1 步的循环遍历，只是循环里调的是 getter |
| **迁移** | P3 用伪代码 `CLASS … ENDCLASS`、类图写它；P4 用 Python 写并运行。记录改写成类是 P3 常见的一道题（⟦9618_s22_32:1(a)⟧ 至 ⟦9618_s22_32:1(c)(ii)⟧）：字段变私有属性、加构造与 getter |
| **在哪里考** | P3-FP-04（术语）、FP-05（补全类图）、FP-06（伪代码定义类）；P4-OP-01 至 OP-07（P4 全卷最大的一块） |
| **最常想错** | ①“private 就是只读”：私有是“只能通过本类的方法改”，setter 就是改它的入口。②对象与类混为一谈：类是模板，对象是按模板造出的一个实例。③P4 考官报告（w24 9618/42）：很多人会声明类和 getter，却不会**实例化**——把数据直接存进数组而不是先 `Obj = ClassName(...)`。④类图里 setter 的名字决定属性名（`SetPatientID` → `PatientID`），自创名字不给分（P3-FP 章首） |

### 第 7 步　文件：结构活到程序结束之后

| | 内容 |
|:--|:--|
| **新增** | 数据在程序外持久保存；文本文件是**一行一个字符串**，没有下标，只能从头读到尾（EOF）；随机文件以记录为单位、可直接定位（SEEK）；打开有模式（读 / 写 / 追加），用完要关闭；打不开要有异常处理 |
| **不变** | 读进来之后立刻变回前面的结构：一行一项 → 数组或栈 / 队列；一行几个字段 → 记录或对象；所以“读文件”题的后半段就是第 1–6 步 |
| **迁移** | 循环从“下标到上界”变成“读到 EOF”；每读一行要**去换行、转类型**，再按第 1–6 步处理；写文件时反过来，数值先转字符串、自己加换行 |
| **在哪里考** | P2-DT-09（读文件逐行处理）、DT-10（写 / 追加 / 复制）、DT-11（用途、模式与格式）；P3-DR-06 / DR-07（组织与存取方式的概念）、FP-10（文件处理伪代码）、FP-11（异常）；P4-FL-01 至 FL-03 |
| **最常想错** | ①把文件当数组 `File[Index]`。②读出来的是字符串：`"42"` 不是 42，`"42\n"` 更不是。③WRITE 会清空文件，要追加用 APPEND。④打开与关闭常合为一分，关闭写在 RETURN 之后等于没写。⑤P4：文件访问放在 `try` 外面，`except` 接不到打开失败 |

### 从模型推出题型：结构 × 动作

任何一道“数据结构”题，都是下面这张表里的一格：横着是结构（第 1–7 步），竖着是六个动作。看到题目先定位到格，模板和得分链就定了。表里填的是题型码（P2 / P3 / P4），空格表示真题里没单独考过。

| 动作 ＼ 结构 | 数组 | 记录（数组） | 栈 / 队列 | 链表 / 二叉树 | 哈希表 | 类 / 对象 | 文件 |
|:--|:--|:--|:--|:--|:--|:--|:--|
| **声明** | P2-DT-03；P4-AR-01 / AR-02 | P2-DT-02；P3-DR-03 / DR-04；P4-AR-03 | P2-DT-16；P3-CT-06 / CT-07；P4-SQ-01 至 SQ-03 | P3-CT-08 / CT-09；P4-LT-01 / LT-03 | P4-LT-05 | P3-FP-05 / FP-06；P4-OP-01 / OP-04 | P2-DT-11（模式）；P3-DR-06 |
| **放一个进去** | P2-DT-05（找空位写入） | P2-DT-07 | 入栈 / 入队：同上 | 插入：P2-DT-15；P3-CT-08 / CT-09；P4-LT-02 / LT-03 | 插入：P3-DR-08；P4-LT-05 | setter / 构造：P4-OP-02 / OP-07 | 写 / 追加：P2-DT-10；P3-FP-10；P4-FL-03 |
| **取一个出来** | — | — | 出栈 / 出队：同上；P4-SQ-04 | 删除：P2-DT-15；P4-LT-02 | — | getter：P4-OP-02 | 读一行 / 一条记录：P2-DT-09；P3-FP-10；P4-FL-01 / FL-02 |
| **找一个** | 线性 / 二分：P3-CT-01 / CT-02；P4-SR-01 / SR-02 | P2-DT-07（按字段找） | — | 沿指针找：P3-CT-08 / CT-09；P4-LT-04 | 按键找：P3-DR-08；P4-LT-05 | — | 逐行比较：P2-DT-09 |
| **走遍全部** | P2-DT-05 / DT-06；P4-AR-04 / AR-05 | P2-DT-07；P4-AR-04 | 反复出栈 / 出队到空：P4-SQ-04 | 遍历：P4-LT-01 / LT-04 | — | 遍历对象数组调 getter：P4-AR-04 / OP-06 | 读到 EOF：同上 |
| **重新排列** | 冒泡 / 插入：P2-DT-08；P3-CT-03；P4-SR-03 / SR-04 | 按字段排：同左 | 用两个栈实现队列：P3-CT-05 | — | — | — | 过滤后复制到新文件：P2-DT-10 |

两个推论：

1. **写代码的得分链在每一格都一样**：模块头 → 声明与初值 → 循环 → 循环里取当前这一个并判断 → 处理 → 循环后输出 / 返回 / 关闭（P2 书末“六环”、P3 书末“五环”、P4 卷首得分链）。换一格只换“当前这一个怎么取”（下标、点号、指针、SEEK、READFILE）和循环怎么停（上界、EOF、空指针、空）。
2. **文字题也在这张表里**：“为什么用记录数组 / 栈 / 链表”（P2-DT-04、DT-12、P3-CT-05）问的都是“这一格比旁边那一格多了什么、少了什么”；答题时写两格的差别，不写一格的定义。

## 主线二　从位到系统再到安全：表示 → 逻辑 → 处理器 → 系统软件 → 通信 → 安全（P1 → P3）

P3 的 DR、BL、HV、SY、CI、SC 六章，每一章都是 P1 某一章的加深版。1 月开始 P3 时，先回到对应的 P1 章读一遍“核心思想”，再看 P3 在它上面加了什么。这条线的每一步都有一个**不变量**——P1 学过、P3 继续用的那个想法。

| 步 | P1 章 → P3 章 | P1 建立的不变量 | P3 新增了什么 | 旧知识怎样搬过来 | 最常想错 |
|:--|:--|:--|:--|:--|:--|
| 1 表示 | IR → DR | **位串本身没有意义，读法决定值**：同一串位可以是无符号数、补码、BCD、字符；装不下就是溢出 | 浮点数 = 两个补码字段（尾数、阶码）；规格化；精度与范围的取舍；用户自定义类型 | 补码的取反加一、“最高位权为负”原样用在尾数和阶码上；溢出的定义不变，只是多了“阶码装不下”；记录类型就是主线一第 2 步 | 阶码写成原码；规格化后忘了调阶码；以为“精度”和“范围”是一回事（尾数管精度，阶码管范围） |
| 2 逻辑 | LG → BL | **真值表是电路的唯一规格**；表达式、电路、真值表三者可互相转换 | 半加器 / 全加器（把加法做成电路）；触发器（**有反馈的电路会记住状态** = 一位存储器）；积之和、卡诺图与布尔代数化简 | 画电路、写表达式、填真值表的方法原样用；化简是“找真值表里相邻的 1” | 卡诺图不按格雷码排；圈了 3 格；把 SR 触发器的“保持”状态当成错误 |
| 3 处理器 | PF → HV | **取指-执行周期**：PC → MAR → MDR → CIR，一条一条执行；中断在周期之间检查 | 流水线：几条指令的不同阶段同时进行；RISC / CISC（指令集设计怎样影响流水线）；并行体系结构；虚拟机 | 中断处理的步骤（P1-PF-04）在 P3-HV-02 原样出现，只是多了“流水线里半截的指令怎么办”；寄存器与总线不变 | 只问 RISC 却拿 CISC 对比；把 virtual machine 答成 virtual memory；以为流水线让单条指令变快（它提高的是吞吐量） |
| 4 系统软件 | SS → SY | **操作系统替用户和程序管理资源**；编译器整体翻译、解释器逐行翻译 | 进程与进程状态、调度算法、虚拟内存与分页；编译的各阶段、BNF / 语法图、RPN | “OS 管理内存 / 进程”在 P3 变成**怎样管**：用中断（第 3 步）把 CPU 轮流分给进程；“翻译”变成词法 → 语法 → 代码生成 → 优化；RPN 用栈求值 = 主线一第 3 步 | 把 running / ready / blocked 的转换条件写反（I/O 请求进 blocked，I/O 完成回 ready，不是回 running）；磁盘抖动写成“磁盘坏了”；RPN 栈里放运算符 |
| 5 通信 | CM → CI | **数据包带着地址走**；拓扑决定线怎么拉；冲突要有办法解决 | 协议栈（四层各做什么、报头层层加）；电路交换与分组交换；应用层协议、BitTorrent | P1 的“数据包怎样走到目的地”就是 P3 的“路由器按报头选路”；P1 的 IP 地址在 Internet 层；CSMA/CD 在 Link 层 | 把层的顺序写错；问协议栈的作用却去描述每一层；只问 packet switching 却写 circuit |
| 6 安全 | SP → SC | **加密让截获者看不懂，签名证明是谁发的、没被改**；哈希把消息压成摘要 | 非对称加密的**用谁的哪把钥匙**；数字证书（公钥可信吗）；SSL / TLS 握手；量子密码 | P1-SP-04 / SP-05 的步骤链在 P3-SC-02 / SC-06 原样出现，只是每一步都要点名钥匙的归属 | 只写 public key 不写谁的；把“私密”和“已验证”两种用法的钥匙弄反；把证书当成加密本身 |

两条跨章的“桥”，P1 和 P3 都会从别的章突然问到：

- **中断**：P1-PF-04（怎样检测、处理）→ P3-HV-02（流水线下的中断）→ P3-SY-03（内核按优先级调度；进程的 I/O 完成也靠中断通知）。它**不是**异常（P3-FP-11）：中断来自硬件或别的程序，异常来自程序自己运行中的意外。
- **栈**：主线一第 3 步的结构，在这条线上出现为“保存现场的地方”——中断时压入寄存器内容（P1-PF-04、P3-HV-02），调用子程序 / 递归时压入返回地址与局部变量（P3-CT-11），RPN 求值时压入操作数（P3-SY-12）。

P1-DB 与 P1-EO 没有 P3 的加深版（P1-EO-04 / EO-05 的 AI 应用与影响，在 P3-AI 变成机器学习的类别与神经网络）；P1-LG 是整条线里唯一“计算题”从 P1 延续到 P3 的章。

### 从模型推出题型：P1 / P3 文字题的四种问法

P1、P3 的描述与解释题，无论哪一章，只有四种问法；每种对应一种答案骨架（细节见各卷书末“解释题得分链”）：

| 问法 | 识别 | 骨架 | 典型题型 |
|:--|:--|:--|:--|
| 它是什么、为什么存在 | define / state what is meant by / explain the purpose | 定义句（限定词写全）+ “so that …”展开 | P1-HW-06、SS-03；P3-FP-11、HV-02、DR-08 |
| 它怎样工作 | describe how / explain how … works / the process of | 按时间顺序一步一句，每句点名主体 | P1-PF-03 / PF-04、SP-05、CM-07；P3-SY-10、CI-06、SC-04 / SC-06 |
| 它和另一样的区别 | difference / compare / contrast / whereas | X …, whereas Y …，每对比同一个方面 | P1-HW-02、SP-08、SS-05；P3-HV-01、CI-07、CT-05 |
| 为什么在这里用它 | justify / explain why … is used / suitable | 它的特性 → 情境的需求 → 特性满足需求（+ 换成另一种会怎样） | P1-IR-14、EO-03、CM-03；P3-CT-05、CT-11、HV-05 |

## 主线三　同一个算法的三种写法：伪代码（P2）→ 伪代码进阶（P3）→ Python 上机（P4）

Richard 的 Python 是弱项，所以这条线按“同一个算法在三张卷上各要什么”来讲，而不是按语言讲。阶梯 L01–L12 负责把伪代码翻成 Python 的手艺；这里说的是**三张卷的 MS 各奖励什么**。

### 第 1 步　P2：手写伪代码，分在得分链上

- 得分点就是书末“六环”：模块头 → 声明与初值 → 循环 → 取当前这一个并判断 → 处理 → 输出 / 返回 / 关闭。算法对不对只占其中两三环，骨架分（头、声明、初值、返回）与算法难度无关。
- **只认指南写法**：混入 `def`、`len()`、`elif`、切片、`for x in` 的那一点不给（D2）。
- 不要求程序能跑：一处 `ENDIF` 漏了只丢一分；思路巧妙但漏了模块头、初值、返回可能丢一半。

### 第 2 步　P3：伪代码进阶——补全、声明、类与文件

- 题型变成“补全给定的伪代码”“声明记录 / 集合 / 类”“写 Push / Pop、二分查找、插入排序、文件处理”。得分链缩成“五环”：声明 → 初值 → 循环与结束条件 → 核心动作 → 收尾。
- 补全题几乎都能从已给的行推出来（配对、对称、名字）；“名字照抄”的分比 P2 更多（类图里的属性名、前一问定义的类型名）。
- 仍然只认伪代码；仍然不依赖 `AND` 短路（D25）；数组仍是带上下界的全局数组（D24）。

### 第 3 步　P4：Python，而且要跑起来、有证据

- 分在三处：**代码本身**（真实的声明、模块头、按题目约定的算法、`return` 而不是 `print`）、**运行结果**（截图要含输入过程、要求同屏的文件名）、**证据文档**（每格贴对、缩进在、黑字白底）。
- **不能用内置函数代劳题目要考的算法**（`sort()`、`in`、`index()`、`max()`，D10），也不能只写注释代替数组声明。
- 代码可以不完整：每个小问独立给分，部分解也贴。

### 三张卷看同一个算法

### 伪代码 → Python 最容易翻错的六处

完整对照在 programming.md §7 与 `ladder/design.md` §5；这六处占了阶梯和 P2 练习里大半的测试失败：

| 伪代码 | Python | 为什么会错 |
|:--|:--|:--|
| `FOR I ← 1 TO N` | `for I in range(1, N + 1)` | `range` 不含终点；下标从 0 起 |
| `MID(S, 3, 2)` | `S[2:4]` | 起点减 1；第二个数是终点不是长度 |
| `X ← X + 1`、`A = B` 判等 | `X = X + 1`、`A == B` | 伪代码 `=` 是比较，Python `=` 是赋值 |
| `PROCEDURE P(BYREF X : INTEGER)` | 返回新值再接住，或 `global` | Python 不能按引用传整数（few-shots 示例 2） |
| `OUTPUT "Total: ", T` | `print("Total:", T)` 或 f-string | `print` 在值之间自动加空格，测试比对输出会挂 |
| `WHILE NOT EOF(F)` + `READFILE F, Line` | `for Line in File:` + `Line = Line.rstrip("\n")` | 行尾换行符；`"42\n"` 转不成整数 |

### 三卷之间不能互相搬的四条规则

1. 伪代码里**没有** `len()`、`range()`、切片、`elif`、`for x in`；Python 里**没有** `←`、`ENDIF`、`MID`。两边各有一套，考哪张卷用哪套（D2）。
2. 伪代码数组的下界由声明给（多数题从 1 起，也有 `ARRAY[0:51]` 这样从 0 起的），循环范围照声明写；P4 的 list 一律 0 起，题目给的下标照用（D24、P4-SQ 章首）。
3. 伪代码不依赖 `AND` 短路；Python 的 `and` 会短路，但按伪代码的习惯写（先判指针再读元素）两边都安全（D25）。
4. P2 / P3 的算法不要求能跑，P4 的要求能跑**并且**不能用内置函数代劳（D10）。
