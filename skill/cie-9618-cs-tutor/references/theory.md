# P1 / P3 理论卷：首学流程、代表题精讲、P3 的逐步作答题与写伪代码题

> 在 SKILL.md 的共用协议之下使用。证据规则、模式、门槛、记录表以 SKILL.md 为准，这里写理论卷特有的做法。

## 1. 两张卷

| | P1 Theory Fundamentals | P3 Advanced Theory |
|:--|:--|:--|
| 时长 / 分值 | 1 h 30 min / 75 | 1 h 30 min / 75 |
| 考纲 | 1–8 节（AS） | 13–20 节（A Level） |
| 手册 | 9 章 88 型：IR → CM → HW → LG → PF → SS → SP → EO → DB | 9 章 79 型：DR → CI → HV → BL → SY → SC → AI → CT → FP |
| 作答 | 笔答：短答、解释、计算、完成表格与图、SQL、汇编追踪 | 笔答：同上，另有浮点、布尔代数与卡诺图、BNF / 语法图、RPN、Dijkstra / A*、写伪代码（类型声明、查找排序、ADT、类、文件）、汇编、Prolog |
| 计算器 | 禁用 | 禁用 |

P3 的大头仍是「一个得分点一分」的描述与解释（HV、CI、SY、SC、AI），写法与 P1 相同；另有两类要专门处理：**逐步作答题**与**写伪代码题**（§6）。19–20 节的算法、ADT、递归、OOP、文件同时在 P3（伪代码笔答）与 P4（Python 上机）考，两边可以挨着学（p4-practical.md §2）。

## 2. 首学单元流程

1. **开章**
   - `rows.py card P<N>-<章码>`：本章考情、核心思想、题型树（★、小问数 / 分值）、易混辨析；`rows.py card P<N>-<章码> --core`：本章概念表（英文得分句带题号 / 中文 / 直观）。
   - 在 [syllabus-map.md](syllabus-map.md) 找考纲节、教材对应节与页码；需要时读教材原文帮自己讲清机制（不整段复制给学生）。
   - 声明语料，展示题型树，抽查几行归类（`rows.py find --type <本章某型>`）。
   - 换章、1 月开 P3、开 P4 之前，读 `docs/guide/concept-threads.md` 里与本章对应的那一步（新增了什么、什么没变、最常想错的地方），开章时用一两句话说出本章在主线上的位置；章首若有「心智模型」段，先讲它再讲题型树。★★★ 卡的「迁移与卡点」块在代表题精讲之后、布置变式之前讲：卡点与反例在讲代表题时说，“从代表题到变式”在布置变式时只说要换的是什么，不说变式的答案。
2. **概念速览**
   - 这一章在解决什么问题、核心模型或机制是什么（例如：CPU 为什么需要 MAR / MDR；为什么要规格化浮点数；为什么非对称加密要两把钥匙）。
   - 术语三层定义（SKILL.md §8）；计算型章节给一个完整的手算示例（§5.1）；结构型内容画图（§5.2）。
   - 指出教材对应节供学生课后读（「教材 Ch16 §16.03，印刷页 320」）。够用即停，具体考法放到题型里讲。
3. **逐型**：`rows.py card <题型码>` → 代表题精讲（§3）→ 变式 → 批改（§4 的批改要点；P3 的两类特殊题见 §6）→ 记录表。
4. **阶段检查**、**章末**：见 SKILL.md §5。

## 3. 代表题精讲（理论版）

每个新题型讲一道代表题（默认卡片的「代表题精讲」那题；刷题清单里任何 2022–2025 题都可以；代表题只有 1 分时，把同一大题里相邻的几问一起讲）。**直接讲，不先让学生做。**

1. **出处与题型**：短格式题号（`s24/12 Q3(b)(ii)`）、分值、题型码。确认已拿到该题 QP 与配对 MS（`rows.py get <行 id> --ms`；有图或排版要紧时 `rows.py render`）。
2. **设问在考什么**：命令词 + 分值 → 需要几个独立得分点（剑桥大多「one mark per point」）；指出题干里与卡片「识别信号」对应的词；用「易混辨析」把它和相近题型分开。
3. **核心概念**：机制、条件、因果关系；新术语三层定义。
4. **完整解答**：按卡片「解题思路」在这道题上走一遍；计算题写出完整手算过程；需要画的画出来。
5. **MS 逐点对齐**：每句话 / 每一步对应 MS 的哪一点。按该 MS 开头的缩写表解读记号：`/` 同一得分点里可互换的词，`//` 同一得分点的另一种答案（不累计），下划线词必须出现，`( )` 里的内容不要求，`…` 开头的点是前一点的展开，`Max n` 封顶，`NE` 不够。区分「讲清原理需要的内容」和「拿分的最低要求」。
6. **考试措辞**：给一段简洁的英文得分答案（包含 MS 得分点），再给中文与直观解释。
7. **易错与失分**：卡片「易错与失分」+ 该题的考官报告摘录（行的 `er`，展示为「考官报告指出 …」）；这份卷有范答或考官点评时（§8）展示相关段落：这个回答为什么满分 / 差在哪一个词。
8. **迁移规则**：同一型换个问法、换个情景时怎么认出来、答案骨架怎么变。

不必死套八步，某步确实不适用就略过；但精确配对 MS、核心推理、MS 逐点对齐三项不能省。

## 4. 各类设问：教法与批改要点

| 设问 | 教法要点 | 批改要点 |
|:--|:--|:--|
| state / identify / give / name | 精确术语；点数 = 分值 | 用词是否就是 MS 的词或其认可的变体；品牌名不给分 |
| define | 三层定义；限定词逐个讲 | 限定词缺一个常常整点不给 |
| describe | 特征或步骤，每点独立成句；只问一样就只写一样 | 点数够不够、彼此是否重复；问 RISC 却写 CISC 不给 |
| explain | 因果链：因为 A → 所以 B；扣情景 | 链条是否完整；是否只复述题干 |
| justify / suggest | 理由必须连到题目给的情景 | 泛泛而谈不扣情景通常不给 |
| compare / contrast / difference | 成对写：X does …, whereas Y … | 只写一边通常只得一半或不得分 |
| calculate / convert | 手算步骤写全（§5.1） | 过程分与答案分分开判；位数、单位、前缀 |
| complete（表格、图、描述填空） | 先给空白结构 | 逐格对 MS；按块或按错误数给分的照 MS |
| draw（逻辑电路、ER 图、语法图、类图） | 用考纲符号；先说关键特征 | 多余的门、缺的连接、缺的标注都会被扣 |
| trace（汇编、算法、递归） | 追踪表逐行；指令集以题目为准 | 每一行的寄存器 / 变量值与输出 |
| write SQL | 表名、字段名照题目抄；语句骨架先行 | 关键字、条件、连接条件、排序 / 分组是否齐 |
| 逐步作答（P3：卡诺图、布尔代数、浮点、RPN、BNF、Dijkstra、A*、汇编、Prolog） | 按卡片「逐步作答模板」 | §6.1 |
| write pseudocode / complete algorithm（P3） | 按 programming.md §4 的编程版步骤 | §6.2 + programming.md §6 |

**看不出理解时问哪一个问题**（SKILL.md §6 理论门槛第 2 条的做法）：先别讲，用 few-shots.md「六种探针」里的一个问题找出缺的那一环——把部件当主体的句子用机制探针（“它自己能做这件事吗？”），定义 / 作用题用反事实探针（“没有它会怎样？”），追踪与指针用状态探针（“此刻是几、从哪看出来？”），易混题型用对比探针。一次一个，最多两个；得分按探针之前的作答判，探针后的改写只写进「解释证据」。每个 ✗ 换成一道 30 秒的检索题写进交接文档「待办 · 下次开场检索」（few-shots.md「把错误转成下一道题」）。

**按章节的常见题型提示**（只是提示，以题型卡为准）：

- P1：信息表示（进制、BCD、补码与溢出、字符集、位图与声音文件大小、压缩）；通信（LAN / WAN、拓扑、以太网与 CSMA/CD、IP、DNS、比特流）；硬件（存储器类型、设备原理、嵌入式、监测与控制）；逻辑门；处理器（冯·诺依曼、寄存器、总线、取指执行、中断、汇编与寻址、位运算）；系统软件；安全与完整性；伦理；数据库（ER 图、规范化到 3NF、SQL）。
- P3：用户自定义类型、文件组织与哈希、浮点；协议与 TCP/IP、电路 / 分组交换；RISC / CISC、流水线、并行、虚拟机；布尔代数与卡诺图、加法器、触发器；调度、内存管理、编译阶段、BNF / 语法图、RPN；加密、证书、签名、SSL / TLS、量子加密；AI（图、Dijkstra、A*、机器学习、神经网络、反向传播）；查找排序、ADT、Big O、递归；编程范式、汇编、OOP、Prolog、文件与异常。

## 5. 手算与作图

### 5.1 手算（全部卷禁用计算器）

学生的作答要写出过程；你示范时也要手算，不跳步。

- **进制**：二进制 ↔ 十进制用位权；二进制 ↔ 十六进制按 4 位一组；BCD 每个十进制数位单独 4 位。
- **补码**：取反加一，或「最高位权值为负」读值；8 位范围 −128 至 +127；溢出看「两个同号数相加得到异号结果」。
- **文件大小**：位图 = 宽 × 高 × 色深（bit）→ ÷ 8 得字节 → 按题目 ÷ 1024（KiB / MiB）或 ÷ 1000（kB / MB）；声音 = 采样率 × 分辨率 × 时长 × 声道数。kibi / mebi 是 1024 的幂，kilo / mega 是 1000 的幂。
- **浮点（P3）**：尾数（mantissa）与阶码（exponent，P3 手册统一叫阶码）都是补码；先读阶码，再移动二进制小数点；规格化：正数尾数以 `01` 开头，负数以 `10` 开头，同时调整阶码；讲清精度（尾数位）与范围（阶码位）的取舍；答案按题目给的位数写满。
- **合理性检查**：每道计算题要求一句数量级或符号检查（「8 位补码结果应在 −128 至 127 之间」「规格化后尾数前两位应不同」）。

### 5.2 作图约定（以题目自己的约定为准）

| 图 | 要点 |
|:--|:--|
| 逻辑电路 / 真值表 / 表达式 | 只用考纲门符号（NOT、AND、OR、NAND、NOR、XOR）；P1 除 NOT 外两输入，P3 可多输入；真值表输入按二进制递增排列 |
| 布尔代数（P3） | `.` = AND，`+` = OR，横线 = NOT；纯文本里单变量写 A̅，整式取反写 NOT(…)；每一步注明用的定律（定律表在 BL 章首） |
| 卡诺图、触发器（P3） | 格雷码顺序、圈 2 的幂、可环绕；每格都填（0 也写）；SR / JK 标输入输出与反馈 |
| 数据结构指针图 | 数组下标 + 内容 + 指针；头 / 尾 / 栈顶 / 空闲表指针；空指针按题目约定；每一步操作后的状态并排画 |
| 二叉树、链表（数组实现） | 结点表（Data、LeftPointer、RightPointer）与树形图对照 |
| 追踪表（dry run） | 列 = 题目给的变量与输出；按执行顺序逐行；赋值语句执行了就记（值没变也记），没执行的才空着；格式与分组照该题 MS（D40） |
| 状态转换图、结构图、流程图 | 状态 / 事件 / 初始状态；模块框与参数箭头；标准符号 |
| ER 图、类图（P3） | 实体与关系线（多对多用连接表化解）；类名、属性（含类型、可见性）、方法、继承箭头、多重性 |
| 网络、TCP/IP 四层、分组交换 | 设备与链路；分层与每层职责；数据包经过的路由 |
| 寄存器传送、取指执行周期 | PC、MAR、MDR、CIR、ACC 的数据流向与顺序 |
| 浮点格式（P3） | 尾数与阶码位宽、二进制小数点位置、规格化前后对比 |
| 进程状态、调度、分页（P3） | running / ready / blocked 及转换条件；调度时间线 |
| Dijkstra / A*（P3） | 结点表逐行更新（当前距离、g / h / f、前驱）；每行只做一个结点 |
| RPN、语法图（P3） | 每读一个符号后的栈状态；语法图的名称、方框、进出箭头 |

## 6. P3 特有的两类题

### 6.1 逐步作答题

题型：卡片写着「解题思路（逐步作答模板）」的型——SY-07～SY-12（BNF、语法图、RPN）、AI-03、AI-04、AI-07（Dijkstra、A*、反向传播）、FP-02、FP-03（汇编）、FP-07～FP-09（Prolog）、SC-02、SC-04～SC-06（密钥、SSL/TLS、证书、签名的过程）；以及按步骤、按块给分的计算与填表题——BL 全章（真值表、积之和、卡诺图、布尔代数）、DR-09～DR-11（浮点）、CT-12（追踪递归）。

- **教**：卡片的解题思路就是答题格式。代表题按它一步一行写出，并说明 MS 把过程分给在哪几步（如 Dijkstra：初始化、每次访问、改写、算式；浮点：指数与过程、尾数；签名：先散列、再用私钥加密散列值）。过程描述题按顺序写，每句一个动作并点名对象（P3 前言通用规则 7）。
- **作答**：学生在对话里按模板写**每一步**（表格用 Markdown 表或拍照）；只给最终答案不够判过程分。题目给了空表 / 空图时，你先给空白结构（SKILL.md §9）。
- **批改**：过程分与答案分分开判；按块给分（真值表每几行一分）、按错误数给分（卡诺图「无错 2 分、一处错 1 分」）、按行给分（A* 表的「某几行」）都照该题 MS；前一步错导致后一步错时，MS 有「follow through」的才顺延给分。
- **门槛**：理论门槛，但「表现」要求过程完整（学生能独立重复整套步骤）；一个小算错不推翻掌握（SKILL.md §6）。
- 汇编只用题目给的指令集；Prolog 的谓词名、参数顺序、大小写照题目；BNF 的元符号照题目给的写法。

### 6.2 写伪代码题

题型：DR-03、DR-05（记录、集合类型声明）、CT-02、CT-03（查找、排序）、CT-06、CT-07（栈、队列）、FP-06（用伪代码定义类）、FP-10（文件处理），以及作答为代码时的 CT-08、CT-09（链表、二叉树）、FP-05（类图）。这些小问 4 分以上的拆了 `markpoints`（带技能标签）。

- **教**：按 programming.md §4 的「代表题精讲（编程版）」：读规格（标识符表、类型、初值、指针约定）→ 设计 → 完整伪代码（逐字按指南、注释标 MP）→ MS 逐点对齐 → 规范要点 → 同题 Python 要点（卡片「同题 Python 版要点 / 与阶梯 / P4 的衔接」）。
- **作答**：学生在对话里写伪代码（代码块）或拍照；填空题只写空格里的内容也可以，但要标清是哪一空。
- **批改**：逐点对该行 `markpoints`（没有时对 `ms_text`），用 programming.md §6 的伪代码规则（D2 / D32：混入 Python 语法的点不给；非指南写法只有该题 MS 显示接受才给）；得分点表格式同 programming.md §6；「规范提示」另列，不扣分的书写细节不扣分。
- **门槛**：理论门槛，**不要求 pytest**。丢分点的 `skills` 写进 P3 记录表「失分技能」（词表 = P2 + P3 扩展）。想让学生把逻辑跑一遍时，可以用对应的阶梯或 P4 练习（`rows.py card` 里的「与阶梯 / P4 的衔接」）做 Python 版——这是加练，不影响 P3 的判定，作答写在那道练习自己的 `attempts/` 路径里。
- P3 的伪代码同样遵守 D24（带上下界的全局数组）、D25（不依赖 `AND` 短路，链表、二叉树遍历用标志或分层判断）。

### 6.3 已核实的官方笔误与缺陷（P3）

| 行 | 情况 | 怎么教、怎么批 |
|:--|:--|:--|
| `9618_w24_31:7(d)(ii)` | MS 印的最简式 `D.(A.B̅)` 是笔误，应为 **D.(A + B̅)** | 教正确式，告诉学生原卷笔误；给分仍按 MS（D41 ②） |
| `9618_s22_31:1(b)(i)` | MS 答案 `DECLARE NumberOfCopies : 1 .. 10` 是范围类型，不在 2027–29 指南里 | 只作为这题的 MS 答案讲，不进模板、不推荐（D41 ③） |
| `9618_s24_31:10(b)` | 官方伪代码在目标小于 `Names[1]` 时会读 `Names[0]`（数组声明 `[1:100000]`） | 照 MS 填空得分；自己写时按模板处理边界（D44 ④） |

## 7. 专项刷题（理论）

1. `rows.py drills <题型码>`：核验语料按新卷在前列出；标出记录表里已做过的、`equivalent_of` 重复的、保留给模考的（s26）。取最新一道没做过的；2021 扩展题在核验题用完或学生要更多时再用（有 MS，可正常批改）。
2. 给题号并展示题目（`rows.py get` 的题干 + 必要时原卷页）；学生在对话里用英文作答，也可以发照片。
3. 按该题 MS 批改，分类错误，按 SKILL.md §7.5 的顺序反馈。
4. 写记录表（日期、题号、得分、错误类别、复测日期）。

考前冲刺与整卷：见 mock-exam.md。

**开场检索（可选，2 分钟）**：交接文档「待办 · 下次开场检索」有题时，在 SKILL.md §2 报告位置之后、首学或复测之前做 2–3 道 30 秒小题（不看笔记、写英文）。✗ 的当场给该题 MS 句或概念表句子，不展开讲；不改记录表（不是复测，复测仍按 SKILL.md §4.5）；次数记进交接文档「常见错误」。示范见 few-shots.md 示例 8。

用法规则：

- 学生作答**之后**再展示；先给 MS 对照，再给范答作「怎么写更稳」的示范。
- 范答、点评与考官报告只说明怎样的答案好、常见错在哪，**给分仍只认该题 MS**；写成「考官报告指出 …」。
- 题型的刷题清单里出现上面这些卷时，可以优先选它们做变式或复测——批改后多一份权威点评。
- 引用时说明来源（如「2024 P1 范答册，Question 4 点评」），不大段复制。
