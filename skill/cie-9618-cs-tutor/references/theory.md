# P1 / P3 理论卷：首学流程与代表题精讲

> 在 SKILL.md 的共用协议之下使用。证据规则、模式、门槛、记录表、作图约定都以 SKILL.md 为准，这里只写理论卷特有的做法。

## 1. 两张卷

| | P1 Theory Fundamentals | P3 Advanced Theory |
|:--|:--|:--|
| 时长 / 分值 | 1 h 30 min / 75 | 1 h 30 min / 75 |
| 考纲 | 1–8 节（AS） | 13–20 节（A Level） |
| 作答 | 笔答：短答、解释、计算、完成表格与图、SQL、汇编追踪 | 笔答：同上，另有浮点、布尔代数与卡诺图、BNF / RPN、伪代码补全与追踪、Prolog 事实与规则、低级语言 |
| 计算器 | 禁用 | 禁用 |

19–20 节（算法、递归、编程范式、文件与异常）同时在 P3（笔答、伪代码）和 P4（上机 Python）考。P3 里出现写伪代码的小问时，按 programming.md 的伪代码批改规则（§6）处理，但掌握门槛按理论题（不要求 pytest）。

## 2. 首学单元流程

1. **开章**
   - 读 `output/p<N>/` 题型手册的该章（或源文件 `papers/p<N>/cards/<章节码>.md`）与概念表该章（`core/<章节码>.md`）。
   - 在 [syllabus-map.md](syllabus-map.md) 找教材对应节与页码；需要时读教材原文帮自己讲清机制（不整段复制给学生）。
   - 声明语料，展示题型树（★、小问数 / 分值、常见题号，来自手册章首的自动块或 `index.json`）。
   - 抽查覆盖：`rows.py find --type <本章某型>` 看几行，确认归类合理；发现明显归错或树里缺了真题出现过的问法，告诉学生并记勘误。
2. **概念速览**
   - 这一章在解决什么问题、核心模型或机制是什么（例如：CPU 为什么需要 MAR / MDR 两个寄存器；为什么要规格化浮点数）。
   - 术语三层定义（SKILL.md §7）；计算型章节给一个完整的手算示例（§5）；结构型内容画图（SKILL.md §8）。
   - 指出教材对应节供学生课后读（「教材 Ch5 §5.06，印刷页 87」）。
   - 够用即停，具体考法放到题型里讲。
3. **逐型**：题型卡 → 代表题精讲（§3）→ 变式 → 批改（§4 的批改要点）→ 记录表。
4. **阶段检查**、**章末**：见 SKILL.md §4。

## 3. 代表题精讲（理论版）

每个新题型讲一道代表题（默认卡片的「代表题精讲」那题；刷题清单里任何 2022–2026 题都可以）。**直接讲，不要先让学生做。** 步骤：

1. **出处与题型**：短格式题号（`s24/12 Q3(b)(ii)`）、分值、题型码。确认已拿到该题 QP 与配对 MS（`rows.py get <行 id> --ms`；有图或排版要紧时 `rows.py render`）。
2. **设问在考什么**：命令词 + 分值 → 需要几个独立得分点（剑桥大多「one mark per point」）；指出题干里与卡片「识别信号」对应的词；用「易混辨析」把它和相近题型分开。
3. **核心概念**：机制、条件、因果关系；新术语三层定义。
4. **完整解答**：按卡片「解题思路」在这道题上走一遍；计算题写出完整手算过程；需要画的画出来。
5. **MS 逐点对齐**：每句话 / 每一步对应 MS 的哪一点。按该 MS 开头的缩写表解读记号，常见的有：`/` 同一得分点里可互换的词，`//` 同一得分点的另一种答案，下划线词必须出现（语法变体可接受），`( )` 里的内容不要求、只提供语境，`max n` 封顶，`NE` 不够（not enough）。区分「讲清原理需要的内容」和「拿分的最低要求」。
6. **考试措辞**：给一段简洁的英文得分答案（包含 MS 得分点），再给中文与直观解释（SKILL.md §7）。
7. **易错与失分**：卡片「易错与失分」+ 该题的考官报告摘录（行的 `er` 字段，或 `_er.pdf` 里该卷该题的段落）；若这份卷有范答或考官点评（§8），展示相关段落：这个回答为什么满分 / 差在哪一个词。
8. **迁移规则**：同一型换个问法、换个情景时怎么认出来、答案骨架怎么变。

不必死套八步，某步确实不适用就略过；但精确配对 MS、核心推理、MS 逐点对齐三项不能省。

## 4. 各类设问：教法与批改要点

| 设问 | 教法要点 | 批改要点 |
|:--|:--|:--|
| state / identify / give / name | 精确术语；点数 = 分值 | 用词是否就是 MS 的词或其认可的变体；品牌名不给分 |
| define | 三层定义；限定词逐个讲 | 限定词缺一个常常整点不给 |
| describe | 特征或步骤，每点独立成句 | 点数够不够、彼此是否重复 |
| explain | 因果链：因为 A → 所以 B；扣情景 | 链条是否完整；是否只复述题干 |
| justify / suggest | 理由必须连到题目给的情景 | 泛泛而谈不扣情景通常不给 |
| compare / contrast / difference | 成对写：X does …, whereas Y … | 只写一边通常只得一半或不得分 |
| calculate / convert | 手算步骤写全（§5） | 单位、前缀、位数、中间步骤 |
| complete（表格、图、描述填空） | 先给空白结构 | 逐格对 MS；不提前填 |
| draw（逻辑电路、ER 图、拓扑） | 用考纲符号；先说关键特征 | 多余的门、缺的连接都会被扣 |
| trace（汇编、算法、递归） | 追踪表逐行；指令集以考纲 / 题目为准 | 每一行的寄存器 / 变量值与输出 |
| write SQL | 表名、字段名照题目抄；语句骨架先行 | 关键字、条件、连接条件、排序 / 分组是否齐 |
| write logic expression / Boolean algebra（P3） | 每一步注明用的定律（De Morgan 等） | 化简结果是否等价、是否最简 |
| write pseudocode / complete algorithm（P3） | 按 programming.md §4 的编程版步骤 | 按 programming.md §6 的伪代码批改规则 |

**按章节的常见题型提示**（只是提示，以题型卡为准）：

- 信息表示：进制、BCD、补码与溢出、字符集、位图与声音文件大小、压缩（RLE）。
- 通信：LAN / WAN、客户端-服务器与对等、拓扑与数据包传输、有线与无线介质、以太网与 CSMA/CD、IP（IPv4 / IPv6、子网、公有与私有、静态与动态）、URL 与 DNS、比特流。
- 硬件：存储器类型（SRAM / DRAM、PROM / EPROM / EEPROM）、设备工作原理、缓冲区、嵌入式系统、监测与控制（传感器、执行器、反馈）；逻辑门与电路。
- 处理器：冯·诺依曼、寄存器、总线、性能因素、端口、取指执行周期与寄存器传送记法、中断；汇编（两遍汇编、寻址方式、追踪）、位运算（移位与掩码）。
- 系统软件：OS 功能、实用程序、程序库与 DLL、编译器 / 解释器 / 汇编器、IDE 功能。
- 安全与完整性：安全 / 隐私 / 完整性区别、威胁与对策、验证与核实（校验、奇偶、校验和）。
- 伦理与所有权：职业伦理、版权、许可类型、AI 的影响。
- 数据库：文件方式的局限、关系术语、ER 图、规范化到 3NF、DBMS 功能、SQL（DDL / DML，最多两表）。
- P3：用户自定义类型、文件组织与哈希、浮点（双向换算、规格化、精度与范围、上溢 / 下溢）、协议栈与 TCP/IP、电路交换与分组交换、RISC / CISC 与流水线、并行架构、虚拟机、布尔代数与卡诺图、触发器、进程调度与内存管理、编译阶段、BNF 与语法图、RPN、加密与数字证书、SSL / TLS、量子加密、AI（图、Dijkstra 与 A*、神经网络、机器学习类别、反向传播与回归）、ADT 与 Big O、递归、编程范式（含低级语言与 Prolog）、文件与异常。

## 5. 手算（全部卷禁用计算器）

学生的变式作答里要写出过程；你示范时也要手算，不跳步。

- **进制**：二进制 ↔ 十进制用位权；二进制 ↔ 十六进制按 4 位一组；BCD 每个十进制数位单独 4 位。
- **补码**：取反加一，或「最高位权值为负」读值；8 位范围 −128 至 +127。加减法写竖式；溢出看「两个同号数相加得到异号结果」。
- **文件大小**：位图 = 宽 × 高 × 色深（bit）→ ÷ 8 得字节 → 按题目要求 ÷ 1024（KiB / MiB）或 ÷ 1000（kB / MB）；声音 = 采样率 × 采样分辨率 × 时长 × 声道数。kibi / mebi 是 1024 的幂，kilo / mega 是 1000 的幂。
- **浮点（P3）**：尾数与指数都是补码；先读指数，再移动二进制小数点；规格化：正数尾数以 `01` 开头，负数以 `10` 开头，同时调整指数；讲清精度（尾数位）与范围（指数位）的取舍。
- **合理性检查**：每道计算题要求一句数量级或符号检查（例如「8 位补码结果应在 −128 至 127 之间」「2 MiB 约是 210 万字节」）。

## 6. 专项刷题（理论）

1. `rows.py drills <题型码>`：核验语料按新卷在前列出；标出记录表里已做过的、`equivalent_of` 重复的、保留给冲刺的（s26）。取最新一道没做过的；2021 扩展题在核验题用完或学生要更多时再用（2021 有 MS，可正常批改）。
2. 给题号并展示题目（`rows.py get` 的题干 + 必要时原卷页）；学生在对话里用英文作答，也可以发照片。
3. 按该题 MS 批改，分类错误，按 SKILL.md §6.1 的顺序反馈。
4. 写记录表（日期、题号、得分、错误类别、复测日期）。

## 7. 考前冲刺（理论）

- **混合题组**：8–12 个小问，跨章混排、不报题型（`rows.py` 输出里的题型码不要转给学生）；包含定义 / 解释句默写（来自概念表的英文得分句与手册书末的解释链）。
- **限时整卷**：1 h 30 min；优先 s26 保留卷，其次用得最少的卷，或 2021 样卷（按样卷自己的 MS）。
- **报告**：按题型列得分；要回炉的题型各附下一道刷题；列出学生写不出的定义句与解释链；按该季 `_gt.pdf` 的分数线估等级。
- 做完后展示该卷可用的范答与考官点评（§8）作为对照。

## 8. 范答与考官点评怎么用

| 资料 | 覆盖的卷 | 用法 |
|:--|:--|:--|
| ECR 2021 P1 / P3 | `9618_s21_13`、`9618_s21_32` | 真实考生 high / middle / low 三档答卷 + 逐点点评：讲「同一道题，三种答案各差在哪」 |
| Example Responses 2024 P1 / P3 | `9618_s24_13`、`9618_s24_32` | 考官写的满分答案 + 常见错误点评：作为措辞范本 |
| SPA P1 / P3 | 2021 样卷 1、3 | 样卷范答 + 点评 |
| 考官报告 | 每季每卷（`_er.pdf` → `Paper 9618/<卷号>` → `Question n`；或行的 `er` 字段） | 该题考生普遍错在哪 |

用法规则：

- 学生作答**之后**再展示；先给 MS 对照，再给范答作「怎么写更稳」的示范。
- 范答、点评与考官报告只说明怎样的答案好、常见错在哪，**给分仍只认该题 MS**。
- 题型的刷题清单里出现上面这些卷时，可以优先选它们做变式或复测——批改后多一份权威点评。
- 引用时说明来源（如「2024 P1 范答册，Question 4 点评」），不大段复制。
