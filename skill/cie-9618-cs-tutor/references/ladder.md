# Python 阶梯：对照卡 → 讲解 → 练习 → 全绿升级

> 在 SKILL.md 的共用协议之下使用。阶梯的课程内容（分级、对照卡、练习规格、过关标准）由 `ladder/` 定义，这里只写教学流程。

## 1. 阶梯是什么

12 级「剑桥伪代码 ↔ Python」阶梯，给一个能读懂简单代码、但还写不出程序的学生打基本功：L01–L08（2026 年 10–12 月）服务 AS 的 P2，L09–L12（2027 年 1–3 月）服务 A2 的 P4。级别、主题与考纲映射以 `ladder/design.md` 为准。

| 文件 | 用途 |
|:--|:--|
| `ladder/design.md` | 分级总表（目标、前置、考纲、公开课讲次）、全局伪代码 ↔ Python 速查表、阶梯与 P2 / P4 题型的衔接、**每级过关标准** |
| `ladder/levels/L<nn>-<slug>/card.md` | 对照卡：本级目标、伪代码 ↔ Python 对照（注明指南页码）、常见坑、延伸阅读、练习清单 |
| `ladder/levels/L<nn>-<slug>/exercises/E<nn>-<slug>/` | 练习文件夹：`task.md`、`starter.py`、`test_task.py`、`answer.pseudo`（需要先写伪代码时）、`files/`、`ref/`（学生先别看） |
| `output/ladder/` | 构建后的阶梯书（`.md` / `.html`）与 `index.json` |
| `ledger/ladder.csv` | 一行一级（类型列为 `L01` 等） |

## 2. 每一级的流程

1. **开级**：一行报告「阶梯 L05 字符串：本级 5 道练习，过关标准 ……」。读该级 `card.md` 与 `design.md` 里本级的目标和过关标准。
2. **讲对照卡**（一次讲完，不拆成很多轮）：
   - **本级目标**：学完能做什么，对应哪些 P2 / P4 题型。
   - **伪代码 ↔ Python 对照**：逐对讲，每对都说「它做什么 → 伪代码怎么写（指南页码）→ Python 怎么写 → 两者哪里不一样」。重点放在不对应的地方：1 起 vs 0 起下标、`MID` vs 切片、`REPEAT … UNTIL` 没有直接对应、`BYREF` 与可变对象、`DIV` / `MOD` vs `//` / `%`、`&` vs `+`、文件读到 EOF 的两种写法。
   - **手追踪一个小例子**：把一段 5–10 行的代码逐行执行，写出变量变化，必要时画追踪表或指针图。
   - **常见坑**：卡片上的坑 + 学生已有的同类错误（看 `ledger/ladder.csv` 与 P2 记录表的错误类别）。
   - 鼓励学生在终端开 `python3` 交互模式把卡片上的小片段敲一遍——敲过比看过记得牢。
3. **练习**（按卡片「练习」顺序，一次一道）：
   - 你运行 `make try EX=ladder/levels/L<nn>-<slug>/exercises/E<nn>-<slug>`，告诉学生读 `task.md`、去写 `attempts/…/solution.py`（`answer.pseudo` 存在时先写伪代码）。
   - 学生说「测一下」：读伪代码（若有）→ 运行 `make try` → 用中文解释每个失败的测试（输入 / 期望 / 实际 / 原因）→ 人工核对清单 → 伪代码按指南逐行核对（阶梯里伪代码不按 MS 给分，只按指南纠正写法）。
   - 卡住时用提示阶梯（programming.md §9）；全绿且核对清单满足才算这道题过。
   - 学生做得快时，可以一次布置两道（「E02、E03 一起做，写完一起测」）。
4. **升级**：按 `ladder/design.md` §4 判定。§4.1 每级通用：本级练习全部全绿且没先看 `ref/`；`answer.pseudo` 按指南逐条核对、改到全对；能讲出卡片「常见坑」里抽的 2 条；**过关小测**——你现编一道本级同类变式（新情境、新数据，不入库），学生先写伪代码再写 Python，20 分钟内完成且自测通过（写在 `attempts/ladder/levels/L<nn>-<slug>/quiz/`，由你用题目样例运行核对）。§4.2 各级专项过关点当场演示。全部满足 → 记录表该级标「已掌握」，进入下一级或回到它解锁的 P2 / P4 题型（SKILL.md §3.4 的交替顺序）；否则「学习中」，在解释证据写清缺口，按加速模式继续下一级，章末复测。

某级在 §4.2 还没有专项过关点时，只按 §4.1 判定。

## 3. 加速节奏下的一条回复

批改上一道练习（测试结果 + 伪代码规范 + 核对清单）→ 更新记录表 → 下一道练习的提示（需要时先补一个对照点）→ 已运行的 `make try` 路径 → 📌 锚点。换级时把新一级对照卡的讲解放在同一条回复里。

## 4. 记录表写法（`ledger/ladder.csv`）

| 列 | 写法 |
|:--|:--|
| 类型 / 名称 / 章节 | 总控生成（`L05` / 字符串 / 阶梯 AS 段） |
| 状态 | 未学 → 学习中（开级即改）→ 已掌握（满足 §2 第 4 步） |
| 独立题目 | 学生独立做出的练习 id，如 `L05/E01；L05/E02` |
| 得分 | `4/5 exercises · 21/23 tests` |
| 错误类别 | SKILL.md §6.2 的固定词表 |
| 失分技能 | 练习 `meta.json` 的 `skills` 里，没做对的那部分对应的标签 |
| 解释证据 | 已掌握：哪道练习说明了掌握；学习中：卡在哪道、哪个点 |

## 5. 公开课材料

对照卡的「延伸阅读」给出 CS50P（https://cs50.harvard.edu/python/ ）与 Think Python 3e（https://allendowney.github.io/ThinkPython/ ）的具体讲次或章节。用法：

- 作为可选的课后读物或视频：学生某个 Python 概念卡住、或想多看一种讲法时，指向卡片列出的那一讲 / 那一节，不泛泛地说「去看 CS50P」。
- 两者都是 CC BY-NC-SA 4.0：可以改编，必须注明出处；只给链接与自己的改写，不整页复制讲义或习题。改编来的练习在 `meta.json` 的 `adapted_from` 里写明出处，讲到时也口头说明。
- 它们教的是通用 Python，不是剑桥写法：与指南或 MS 习惯冲突时（例如考试代码里用显式循环而不是推导式），以剑桥为准，并说明原因。

## 6. 给 Python 初学者的讲法

- 每段新代码先说「每行做什么」，再说「为什么这样写」；变量是「名字贴在值上」，不是「装值的盒子」——这对后面讲可变对象与 BYREF 很关键。
- 报错是信息，不是失败：教学生从 traceback 最后一行读起（programming.md §9）。
- 先写贴近伪代码的 Python（显式循环、下标、`while`），等结构稳了再介绍地道写法（`for x in list`、`enumerate`、`with open`），并说明 P4 里两种都能得分、题目要求实现某算法时必须写出算法本身。
- 小步验证：写几行就运行一次，或在交互模式试；不要一口气写完再调。
