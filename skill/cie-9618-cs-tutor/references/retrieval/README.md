# 开场检索题库

这四份题库给教学会话的开场使用。每道题只取一个题型卡里的卡点，学生不看笔记，用英文在约 30 秒内回答；导师再用 `retrieval.py show` 查看答案和 MS 原句。检索是找回上次缺的那一环，不是复测，因此不改 `ledger/` 的状态、得分或独立题目。

## 文件和格式

- `P1.md` 至 `P4.md` 按卷、章、题型码排列。题型名称与 `output/p<N>/index.json` 的 taxonomy 一致。
- 题号固定为 `<题型码>-R1`、`<题型码>-R2`。`〔原情境〕` 是代表题模型的短探针；`〔换情境〕` 把同一模型搬到另一设备、数据结构或场景。每个 ★★★ 型至少有一题换情境，★☆☆ 型不进题库。
- 每题固定三行：`Q:` 是给学生看的英文题面，`A:` 是导师看的答案，`测：` 是中文卡点说明。答案若采用 MS 句，必须是 `「原句」⟦行 id⟧`；自行组织的代码或句子要写 `（非 MS 原文）`，代码不超过三行。
- 题库只引用题型卡或章概念表已经出现的 MS 行。不得用 s26 行；s26 留给限时整卷模考。`make check` 会逐字核对所有引用。

## 开场怎么用

1. 先按学习会话的报告骨架读 `ledger.py summary`，确认要复习的卷和到期日期。
2. 从学习中的题型先抽 2–3 道；有到期复测时仍先按教学协议提议一道复测，学生可以跳过。检索题只作为首学或复测前的两分钟热身。
3. 学生不看笔记写英文。按题库答案批改：答对只指出他已经能迁移；答错只给对应 MS 句或概念表句子，不展开讲解。
4. 每个错点在交接文档的“常见错误”和“下次开场检索”里记一次。连续两次答对才从清单删除；检索本身不写入记录表。

默认从当前工作区的记录表抽题：

```bash
python3 skill/cie-9618-cs-tutor/scripts/retrieval.py pick P1 --n 3
```

`pick` 先按 `状态=学习中` 的 `复测日期` 排序，过期的最先；数量不够时，再按 `已掌握` 的 `日期` 最早者做间隔复习。每个题型最多抽一道，优先选换情境题。题面输出不含答案。可以指定题型、避开上次题号或固定随机种子：

```bash
python3 skill/cie-9618-cs-tutor/scripts/retrieval.py pick P1 \
  --types P1-HW-06,P1-IR-05 --avoid P1-IR-05-R1 --seed 7
```

实测或演示时，把 `ledger/P1.csv` 复制到 `work/tmp/`，再用 `--ledger work/tmp/P1.csv`；不要修改真实记录表。

导师批改时查看答案：

```bash
python3 skill/cie-9618-cs-tutor/scripts/retrieval.py show P1-IR-05-R1 P1-HW-06-R2
```

检查题库格式、引用禁区与星级覆盖：

```bash
python3 skill/cie-9618-cs-tutor/scripts/retrieval.py check
python3 skill/cie-9618-cs-tutor/scripts/retrieval.py check P2
```

`check` 的星级只读构建出来的 `output/p<N>/index.json`，不读记录表的“优先级”列。若索引不存在，先运行 `python3 build/build.py all`。检查会报告题数和换情境比例，并拒绝重复题号、缺字段、未知题型、没有答案证据、s26 行或不足的星级配额。

## 怎样补一道题

先在题型卡的“迁移与卡点”里找一个缺环，再查看该卡的“得分表述”和章概念表，选择代表题或变式里已经出现的非 s26 MS 行。问题要换一个短情境，只问一环，不把整道真题搬过来；答案用该 MS 行逐字引用。★★★ 型把第二题写成 `〔换情境〕`，同一模型换设备、数据结构或场景。写完先运行 `retrieval.py check P<N>` 与 `make check`；临时现编但值得保留的题记进交接文档，交给总控收回题库。
