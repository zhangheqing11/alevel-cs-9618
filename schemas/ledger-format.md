# 掌握记录表格式 `ledger/*.csv`

一卷一个文件：`ledger/P1.csv`、`P2.csv`、`P3.csv`、`P4.csv`，阶梯 `ledger/ladder.csv`。编码 `utf-8-sig`，一行一个题型（或一级阶梯）。初始文件由各卷题型体系合并时总控从 `taxonomy.json` 生成，此后只由学习会话改写。

| 列 | 说明 |
|:--|:--|
| 类型 | 题型码（`P1-DB-03`）或阶梯级（`L05`） |
| 名称 | 中文名 |
| 章节 | 章节码 + 中文名 |
| 优先级 | ★☆☆–★★★（来自构建统计） |
| 状态 | `未学` / `学习中` / `已掌握` |
| 日期 | 最近一次状态变化日期 `YYYY-MM-DD` |
| 独立题目 | 学生独立完成的题，行 id 或练习 id，多个用 `；` |
| 得分 | 如 `4/5`；编程题加测试结果 `4/5 · 6/7 tests` |
| 错误类别 | 见教学 skill 的错误分类，多个用 `；` |
| 失分技能 | 编程题：丢分得分点的技能标签，如 `file-close；loop-to-eof` |
| 解释证据 | 掌握证据或未解决的具体缺口 |
| 复测日期 | 计划复测日期 |
| 复测结果 | 复测题与得分 |
