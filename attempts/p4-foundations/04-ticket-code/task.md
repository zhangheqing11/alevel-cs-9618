# P4 基础练习 04：生成入场票编号

自编课堂练习，不按官方评分方案计分。

## 题目

编写一个 Python 程序：

1. 输入观众姓名（英文，例如 Alex）。
2. 输入座位排号（正整数）。
3. 生成入场票编号：姓名、一个英文短横线、排号，三部分依次连接，中间没有空格。
4. 输出一行：`Ticket: ` 后接完整编号。冒号后恰好一个空格。

## 要求

- 使用变量名 `name`、`row`、`ticket_code`。
- 输入顺序为姓名在前、排号在后。
- `name` 保存字符串，`row` 必须保存整数。
- 本题专门练习字符串拼接：生成 `ticket_code` 时必须使用 `+` 和 `str()`，不要用 f-string 代替这一步。
- 输出方式可以自行选择，但必须符合规定格式。
- 输入提示语使用英文，写在 `input()` 的括号里。
- 假设输入合法，不需要检查空姓名、非法排号或处理额外空格。
- 本题不需要另写伪代码。
