# P4 基础练习 03：笔记本总价

自编课堂练习，不按官方评分方案计分。

## 题目

商店出售笔记本。编写一个 Python 程序：

1. 先输入一本笔记本的单价，单价可以有小数。
2. 再输入购买数量，数量为整数。
3. 计算总价。
4. 最后一行只输出总价，固定保留两位小数，不加货币符号或说明文字。

## 要求

- 使用变量名 `unit_price`、`quantity`、`total_price`。
- 输入顺序：单价在前，数量在后。
- 输入提示语使用英文，写在 `input()` 的括号里。
- 假设单价与数量均为合法的非负输入，不需要处理非法输入。
- 总价等于单价乘以数量，不涉及折扣或税费。
- 本题不需要另写伪代码。

## 作答方式

在同文件夹的 `solution.py` 中编写代码。可以自行运行检查。
保存后回到学习对话说“第三题写好了，测一下”。
