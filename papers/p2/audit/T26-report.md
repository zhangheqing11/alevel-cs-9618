## 全部error与原件证据

### F01 · P2-DT-11 · concept

位置：`papers/p2/cards/DT.md:1125`；锚定行：9618_s22_23:9(c)。

QP 9618_s22_qp_23.pdf p.18 只说 encrypted password 可含任意字符；同题 MS 9618_s22_ms_23.pdf p.11 明列满分 separator 方案：选择不会出现在 domain name 的字符（如空格），接域名、分隔符、加密密码。故本卡 1125、1139、1155 行“数据可含任意字符就只能用长度前缀”的总规则过强，并与 1149 行正确范答相冲突。

建议：区分“一个字段可含任意字符”和“所有待分隔字段都无可排除字符”；说明本题只寻找域名后的第一个分隔符，密码中再出现同一字符不影响拆分。

### F02 · P2-SD-07 · concept

位置：`papers/p2/cards/SD.md:437`；锚定行：9618_w23_23:5。

QP 9618_w23_qp_23.pdf pp.10–11；MS 9618_w23_ms_23.pdf p.8 的表在第4、5次迭代均再次填写 Index=2（与前次相同），与“值没变就不写”冲突。同卡范答也保留这些2。core/SD.md:115 重复同一规则。原页 Value 与 Total 可在同一表行，亦不能把“每次赋值必须另起一整行”当固定版式要求。

建议：改为逐条执行赋值、按题目与该题 MS 的追踪表约定记录；区分“语句没执行”与“语句执行但赋得相同值”，不要一概删掉后者。同步修正 core/SD.md:115。

### F03 · P2-DT-14 · concept

位置：`papers/p2/cards/DT.md:1280`；锚定行：9618_w21_21:3(a)(iii)。

所引 9618_w21_ms_21.pdf p.5 的“只有一项”在该题指针约定中成立，不能推广为所有队列的相等判据。反例：9618_s26_qp_21.pdf p.15 Q7(c) 明说 initially empty；其自己的 MS 9618_s26_ms_21.pdf p.12 允许 Front、Rear 同设0（或同设其他允许值）来初始化空队列。本卡1276行也承认指针约定有差别。

建议：限定：仅在 FoQ 指首项、EoQ 指末项且队列非空的约定下，相等表示一项；空/满应结合本题初值、计数器或留空位规则判断。s26仅作现有统计/概念规则核验，不作为代表/变式。

3. **选题规则**：92个代表/变式引用均满足2022–25、primary相同、非equivalent_of；46组均不同卷。未取s26作代表或变式。D1允许概念引文及核验统计包含s26，故不把现有s26概念引文误报为选题违规。
4. **事实与计数**：46张卡的分值、Max、代表题点数人工对原页；18幅地图147列脚本重算，见下节。读完构建后的考情、题型树与刷题清单：s26保留标记、2021扩展单列，未见残留auto占位块。
5. **QP定位**：18个QP页码提示逐处回看所指对象。F04是图页与作答页混淆；SD-12的p.6确为旧算法步骤，虽然3(c)题目在p.7，因此不误报。
6. **概念与跨章入口**：四份core、front/back全部阅读，跨章入口和优先级与tagging guide一致；主要问题F01–03、F07–10、F13。伪代码人工核对2027–29指南pp.7–8、10、13、15–25与当卷插页函数：关键字、赋值箭头、类型/数组、终结符、BYREF、文件、参数顺序与短路。按原题保留Sub-A等原有模块名、SD-08明确标识的关系式CASE，以及含错原代码，不当成新模板lint错误。
