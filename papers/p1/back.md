## 书末　跨章入口、解释题得分链与命令词 {#back}

前面 9 章按题型拆开讲；真卷里一道大题往往跨好几章，文字题的得分方式也有几种固定套路。本部分把它们收拢：①看到一个情境，预判会从哪几章出题；②Explain / Describe 类解释题怎样按 MS 的给分结构组织答案；③每个命令词要你做什么。每一条都配了真实例题行，学的时候回到对应题型卡。

### 跨章入口：同一情境常跨哪些章

P1 的大题先给一段情境，再在同一情境里连问 4–8 个小问。读完情境先想一想“这个情境天然会牵出哪些题型”，做到一半就不会被突然换章打乱节奏。

两个提醒：

1. **情境不决定题型，命令决定**。数据库情境里问“怎样校验 RiderLevel 字段”是 SP-06（⟦9618_s23_12:2(c)(i)⟧），安全情境里问“AI 怎样做人脸识别”是 EO-04（⟦9618_s24_11:5(c)(ii)⟧）。先看这一小问在问什么，再去对应的题型卡找套路。
2. **前面小问给的信息，后面要用**。数据库大题后面的 SQL 要用前面给的表名、字段名；规范化后的新表会在后面的 E-R 图或查询里再出现。

### 解释题得分链

Explain / Describe 类题目占 P1 文字题的大头。MS 的得分点不是随便列的，它们有几种固定结构；看清是哪一种，答案就照那个结构写，每一句对一个得分点。

#### 链 1　做法 → …so that 结果

**结构**　MS 先列一个做法（1 分），再列一个以 `…` 开头的展开点（1 分），说明这个做法带来什么、为什么有用。“…”点不能单独成立，必须跟在它的做法后面。

**骨架**　*Do X, so that Y.*　每个做法配一个 so that / because / which means。

**例**
- 限制恶意软件：「Download programs from reputable websites / sources」⟦9618_w23_13:8(c)⟧ 后接「as these are less likely to contain malware」⟦9618_w23_13:8(c)⟧。
- 写光盘时的缓冲区：先说两者速度不同、缓冲区临时存放数据，再接「so that the computer can transfer data to the buffer at the higher speed」⟦9618_w24_11:3(d)(ii)⟧。
- 程序库的好处：「Programming time is saved as code does not have to written from scratch」⟦9618_w25_13:8(b)⟧——好处与原因写在同一句里。

**适用**　好处、作用、措施类：SP-03、SS-02、SS-03、HW-06、EO-01、DB-01。

#### 链 2　按顺序的过程步骤

**结构**　MS 把一个过程拆成 5–8 个先后步骤，每步 1 分，分值通常少于步骤数。顺序本身不单独给分，但写乱了常常漏步。

**骨架**　*First … → then … → … → finally …*　按时间顺序一句一步，主语写清楚（sender / receiver、the workstation、the CPU）。

**例**
- 数字签名：发送方哈希 → 加密摘要 → 发送 → 接收方解密 → 重新哈希 → 比较（⟦9618_s25_11:7(b)⟧，见 SP-05）。
- CSMA/CD：「The workstations listen to the communication channel」⟦9618_w25_12:5(d)⟧ → 线路空闲才发送 → 检测到冲突就停止并发出干扰信号 → 随机等待后重发。
- 中断处理：在 F-E 周期开始或结束时检查中断寄存器 → 比较优先级 → 「the contents of the registers are stored on the stack」⟦9618_s25_12:1(c)⟧ → 调用 ISR → 恢复寄存器、继续下一个周期。
- 实时位流：连续发送一串位 → 上传到媒体服务器 → 下载到用户设备的缓冲区 → 从缓冲区播放（⟦9618_s25_11:2(a)⟧）。

**适用**　how … works / describe the process：SP-05、SP-07（checksum）、CM-07、PF-03、PF-04、CM-12、PF-07。

#### 链 3　成对比较：X …, whereas Y …

**结构**　每个得分点同时写出两边在同一方面的不同。只写一边的句子通常不给分。

**骨架**　*X does …, whereas Y does …*　每一对比较同一个方面（存储方式、速度、价格、用途）。

**例**
- DRAM 与 SRAM：「DRAM stores each bit as charge SRAM uses flip-flop to store each bit」⟦9618_w25_11:6(c)⟧。
- 监测与控制系统：「Control systems use actuators monitoring systems do not have any actuators」⟦9618_w25_11:9⟧。
- 验证与校验：「data verification is checking if input data is the same as the original whereas data validation is checking that the data is reasonable / sensible」⟦9618_w22_12:4(a)⟧。

**适用**　difference / compare / similarity：HW-02、HW-08、SP-02（pharming vs phishing）、SP-08、SS-04、SS-05、CM-01。

#### 链 4　选择 + 扣情境的理由

**结构**　先选一个（压缩方式、许可、系统类型、拓扑），选择本身常常**不给分**；分数在理由上，理由必须扣题目情境。

**骨架**　*Choice: X. Because [feature of X], [benefit in this scenario].*　选择不给分时，理由要写满分值那么多条；选择给 1 分时，写“分值减一”条。每条理由都提情境里的人或物。

**例**
- 实时位流选压缩方式：「No mark for choice but lossy is most appropriate」⟦9618_s25_11:2(b)(ii)⟧，分全在“文件更小 → 带宽更少 → 缓冲更少”这类理由上。
- 自动门：「Control system (no mark)」⟦9618_w25_12:11⟧，理由要写执行器开门、开门改变传感器的输入、系统按反馈自动动作。
- 卖给公众的游戏选许可：选 commercial 1 分，理由各 1 分（⟦9618_s23_13:5(b)⟧，见 EO-03）。

**适用**　identify / tick … and justify：IR-14、HW-08、EO-03、CM-03、SS-05、HW-01。

#### 链 5　分栏作答：两部分各封顶

**结构**　题目点名两件事（两个工具、两种角色、两个阶段），MS 每一栏单独封顶。一栏写得再多也补不了另一栏。

**骨架**　题目给了两个标题就用两个标题分开写，每栏写到它的上限。

**例**
- 先用解释器、后用编译器：「Max 2 from each section」⟦9618_w25_12:10(a)⟧。
- 内存管理与进程管理怎样支持多任务（⟦9618_s24_12:6⟧，每项最多 3 分）。
- 录入分数时的校验与验证：校验最多 3、验证最多 2（⟦9618_s22_11:4(d)⟧，见 SP-08）。
- 对同事与对公众合乎道德（⟦9618_w24_12:5(a)⟧，各 2 分）。

**适用**　Explain how A and B …：SS-01、SS-05、SP-08、EO-02、HW-08。

#### 链 6　好处 + because 机制（成对给分）

**结构**　MS 写明 Mark in pairs，或把好处与它的原因写成两个相连的点：好处 1 分，“因为”1 分。

**骨架**　*Benefit, because mechanism.*

**例**
- 关系数据库解决文件方式的局限：「Mark in pairs」⟦9618_s23_13:4(a)⟧，例如“减少冗余”+“因为表相互链接，每个数据项只存一次”。
- 解释器的优点：“easier to debug the program”后接「because it translates line-by-line and stops when an error is found」⟦9618_w23_11:6(a)⟧。

**适用**　advantages / benefits：DB-01、SS-05、SS-03、IR-13、CM-01。

#### 链 7　局限：它查什么、不查什么

**结构**　问“为什么做了 X 之后仍然可能不对 / 不安全”。答案是把 X **能做的**和**做不到的**并排写出来。

**骨架**　*X only checks …; it does not check …*

**例**　校验与验证之后数据仍可能错（⟦9618_s22_13:5(b)(iii)⟧）：校验只查合理性，不查准确性；验证只查与原件一致，不查原件本身对不对。

**适用**　SP-08；也可迁移到“加密之后数据仍可能被截获”（加密不阻止截获，只让截获者看不懂，SP-04）。

#### 链 8　影响：哪类影响 + 落到谁身上

**结构**　影响题常是“影响 1 分 + 对应描述 1 分”。影响要属于题目点名的那一类（社会、经济、伦理），描述要落到情境里的具体对象。

**骨架**　*[Impact of the named type], because / so [who is affected and how].*

**例**　修理厂的 AI 诊断模块：「1 mark for a correct economic impact and 1 mark for corresponding description」⟦9618_w22_13:8(b)⟧——“降低成本”+“因为诊断用时更少”。

**适用**　EO-05；也适用于 CM-08（云计算对公司的影响）等“effect / impact”类题。

### P1 常见命令词的作答要求

P1 出现最多的命令词依次是 Describe、Explain、Complete、Identify、Write、State、Give。下表按“要你做什么 → 怎样拿分”排列，每个配一道真题。

| 命令词 | 要你做什么 | 怎样拿分 | 例 |
|:--|:--|:--|:--|
| State / Give / Name | 给出一个事实、名称或简短的一句 | 点数 = 分值；用 MS 的术语原词；不写品牌名 | ⟦9618_w23_12:5(a)⟧ |
| Identify | 从情境、表格或算法里认出并说出名称 | 名称本身常 1 分；后面跟 describe / justify 时，分数主要在后半 | ⟦9618_w24_13:4(a)⟧ |
| Define / State what is meant by | 给术语下定义 | 限定词一个都不能少（unique、temporary、per second）；三层定义里的英文句可直接默写 | ⟦9618_w23_12:2(a)⟧ |
| Describe | 说出特征或过程的各个步骤 | 每点独立成句；过程题按顺序（链 2）；不必解释原因 | ⟦9618_w25_12:5(d)⟧ |
| Explain | 说明原因、机制或怎样起作用 | 因果链：做法 → so that 结果（链 1、6）；扣情境 | ⟦9618_s24_11:5(c)(i)⟧ |
| Justify | 给选择提供理由 | 选择本身常不给分；理由连到情境（链 4） | ⟦9618_s25_11:2(b)(ii)⟧ |
| State the difference / Compare | 比较两样东西 | 成对写，X …, whereas Y …（链 3） | ⟦9618_w25_11:6(c)⟧ |
| Discuss | 讨论两面（好处与坏处） | 两面都要写，只写一面会被封顶 | 见卷首通用得分规则 6 |
| Complete（表格 / 描述 / 填空） | 填满每一个空格 | 一格或一行一分；填空用规范术语；表格两栏要配套 | ⟦9618_w25_12:2(a)⟧ |
| Draw / Complete the diagram | 画逻辑电路、E-R 图、拓扑、连线 | 该有的连接都有、没有多余的连接；连线题看清“全对才给分”还是按条给 | ⟦9618_w22_11:4(a)⟧ |
| Tick | 每行勾一个（或一个或多个）框 | 按勾对的行数分档；带 justify 时分在理由上 | ⟦9618_w23_12:6(a)⟧ |
| Convert / Calculate / Show your working | 进制转换、文件大小、二进制运算 | 「1 mark for working; 1 mark for answer」⟦9618_s23_11:1(b)(ii)⟧：写出过程，单位与位数按要求 | ⟦9618_s23_11:1(b)(ii)⟧ |
| Trace | 逐条执行汇编程序、填跟踪表 | 「1 mark for each set of highlighted rows」⟦9618_w22_12:7(a)⟧：每一组行都要对；哪些格要填按该题 MS 的表（执行了的赋值就记，值没变也记，没执行的才空着——D40），不要自己发明“只记变化” | ⟦9618_w22_12:7(a)⟧ |
| Write（逻辑表达式） | 由电路或描述写出布尔表达式 | 按子表达式给分；括号表明运算顺序 | ⟦9618_w24_11:5(b)⟧ |
| Write（SQL 脚本） | 写 DDL 或 DML 语句 | 一子句一分；表名、字段名照抄；字符串加引号、日期加 #（见 DB 章 SQL 速查） | ⟦9618_w25_11:2(c)(ii)⟧ |
| Circle | 在给出的数据上圈出答案 | 只圈一个，圈清楚 | ⟦9618_w25_12:6(c)(ii)⟧ |

最后一条通用提醒：**分值就是要写的点数**。2 分题写两个独立点，4 分题写四个；把握不大时多写一个正确的点作保险；但同一个意思换说法只算一次，前后矛盾的说法也可能让那一点不给分。
