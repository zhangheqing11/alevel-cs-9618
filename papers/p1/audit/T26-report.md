## error逐条说明

### F01 · 星型拓扑范图的路由器连线错误

- 位置：`papers/p1/cards/CM.md:151`；P1-CM-03；`answer-not-full-marks`。
- 原件与判断：9618_s25_12:6(d)。QP p.12 要求星型网络图；MS p.11 的路由器点要求 “Router / modem directly connected to the switch / server for internet access”，原页示例亦直连 switch。卡内示意图将 Router 的竖线放在 Computer 3 下方，呈现 Computer 3 → Router 的串接，与紧邻文字及该得分点冲突。照图抄写有丢路由器连接分的风险。
- 建议：重画示意图，使路由器的线明确直接接 SWITCH 或 Server；复核 Markdown/HTML 成品中所有分支。保留正确的文字说明。

### F02 · 4分社会影响题只覆盖3个独立得分点

- 位置：`papers/p1/cards/EO.md:262`；P1-EO-05；`answer-not-full-marks`。
- 原件与判断：9618_w25_11:8(c)。QP p.14 为4分；MS p.13 每个 bullet 1分、max 4。影响1中的 reasoning/problem-solving、not learning、decline in skills 是同一 bullet 内 // 分隔的替代表述，只能算1点。影响2覆盖 communication 与 anxiety/loneliness 两个 bullet。完整作答及英文范答合计只覆盖3个独立 bullet，不能据此承诺4分；对齐说明把第一条的替代表述当展开得分。
- 建议：在题目要求的两项影响内组织出4个独立MS要点（如在学习影响内补充错误答案导致misinformation），并重写满分答案和对齐说明；不要把 // 内的改写累计给分。

### F03 · ACC被归为通用寄存器

- 位置：`papers/p1/core/PF.md:19`；P1-PF-02；`concept`。
- 原件与判断：9618_w23_11:5(a)。本行中文将ACC称为通用寄存器。9618_w23_11 QP p.9 明确把 MDR、IX、ACC 列为 special purpose registers，然后要求 two other；其 MS p.7 的候选为 PC、MAR、CIR、SR。引用的9618_w25_11:6(a) MS p.10只支持ACC的作用，不支持“通用”分类。
- 建议：按本考纲/真题的模型改称专用寄存器；保持运算结果的功能描述。

### F04 · 部分依赖术语下放了“无部分依赖”的句子

- 位置：`papers/p1/core/DB.md:31`；P1-DB-05；`quote-misuse`。
- 原件与判断：9618_s22_11:4(b)。QP p.7 问MARKS的最高范式及理由，MS p.5 的 “Each field is fully dependent on the corresponding primary key // no partial dependencies” 是说明不存在部分依赖。概念表却把该句放在 Partial dependency 的英文得分句列，与本行中文“只依赖复合主键的一部分”相反；按卷首建议直接默写会把有/无说反。
- 建议：英文列改为部分依赖的正向定义并标非MS原句，或将本行明确改名为 No partial dependencies 并同步中文。保留来源的真实语境。

### F05 · 传递依赖术语下放了“无传递依赖”的句子

- 位置：`papers/p1/core/DB.md:33`；P1-DB-05；`quote-misuse`。
- 原件与判断：9618_w22_11:4(b)。QP p.7 问3NF特征，MS p.5 的 “no non-key dependencies // no transitive dependencies” 指不存在非键/传递依赖。表中术语及中文定义却描述依赖本身，英文是其否定，不能作为该术语的可默写定义。
- 建议：用正向英文定义说明非键属性依赖另一非键属性（注明非MS原句），或改成“无传递依赖”并对应3NF条件。

### F06 · 把两位错误必漏检推广到块奇偶校验

- 位置：`papers/p1/cards/SP.md:369`；P1-SP-07；`concept`。
- 原件与判断：9618_s24_13:7(f)(i)。卡将“两位同时翻转时奇偶不变，查不出来”作为刚介绍完 parity byte 与 parity block 后的通用结论。该题 QP p.16 / MS p.9 区分逐字节奇偶与横纵块校验。两位翻转只有位于同一校验组时才保持该组奇偶性；若同一行的两列翻转，行奇偶不变，但两个列奇偶都会改变，因此 parity block 仍能发现。
- 建议：限定为“同一字节内偶数个位翻转可能绕过单字节奇偶检查”；单独说明块校验仍检查各列，不能套用两位必漏检。

### F07 · 把外键所在端一律当成多端

- 位置：`papers/p1/cards/DB.md:246`；P1-DB-04；`concept`。
- 原件与判断：9618_w24_12:6(b)(i)。卡把“有外键的一端就是多端”作为无条件画图规则，DB-03解题思路第1条及章末DB.md:810亦复现。9618_w24_12 QP p.8 / MS p.7 明确给出 EMPLOYEE → LOGIN_DATA 为1:1，同时用EMPLOYEE主键在LOGIN_DATA作外键实现。故仅靠外键所在位置不能断定1:M。
- 建议：补上外键可重复时才是多端；若外键唯一/同时为主键，须结合题目约束判1:1。同步修订DB-03及章末辨析的同类断言。

### F08 · 无条件把主键排除出候选键

- 位置：`papers/p1/cards/DB.md:159`；P1-DB-02；`concept`。
- 原件与判断：9618_w22_12:5(c)。本行无条件要求candidate key是主键之外“另一个”字段；解题思路第3条也排除主键。所引概念题 QP p.7 / MS p.6 定义为可成为主键的属性/属性组，没有“尚未选中”的限制。已选主键仍属于候选键；“未选中”是该卡secondary/alternative key的口径。
- 建议：区分集合关系：主键从候选键中选择。仅在题目明确要求 another/other，或说明寻找未被选为主键的键时，才排除已选主键。

### F09 · 移位的乘除规则缺少溢出及取整条件

- 位置：`papers/p1/core/PF.md:43`；P1-PF-11；`concept`。
- 原件与判断：9618_s25_13:7(a)(i)。中文列无条件写“左移n位×2ⁿ，右移n位÷2ⁿ（无符号）”，漏掉卡PF-11已写的“未溢出”和右移取整条件。原题QP p.17 / MS p.12 给8位11001010左移2位=00101000，表明移出位丢弃。自编无符号反例：240在8位左移1位为224而非480；5右移1位为2而非2.5。
- 建议：补回“左移仅在未丢有效位时等于乘2ⁿ；无符号右移等于除2ⁿ后向下取整”，并优先教逐位移动规则。

### F10 · 把copyleft约束推广到全部OSI许可

- 位置：`papers/p1/cards/EO.md:135`；P1-EO-03；`concept`。
- 原件与判断：9618_w25_12:2(a)。将OSI类开源软件再发布一律限定在“同样的许可条件下”，core/EO.md的OSI中文也如此。该题QP p.2 / MS p.4仅说可复制、分发、修改，并未规定统一的相同许可。教材 Langfield_Duddell_Coursebook_2e_2019.pdf PDF p.158（印刷p.152）区分：OSI按具体license条款；随后另以copyleft说明修改版须保持相同使用条件。卡把后者推广到了全部开源许可。此处是概念审计，不据教材改给分。
- 建议：OSI栏改为“可以，遵守具体许可证条款”；将保持相同许可/自由的要求限定到要求它的copyleft许可证，并同步core/EO.md。
