> 2027 年 5–6 月考季用。核验语料为 2022–2026s 全部 variant，2021 单列为扩展。给分只认当前题自己的 QP 与同季、同年、同 variant 的 MS；ER 只解释易错。Python 是本系统的上机语言，伪代码对照按 2027–29 版剑桥指南。

## 使用指南

### 从一道大题到一个题型

P4 要把题目要求做成能运行的控制台程序，再把指定代码与测试截图放进证据文档。一个大题通常拆成几种技能：先声明结构，再写操作，读入数据，调用模块，最后测试。题型卡按得分动作组织，帮助你看出当前小问是在考哪一步。

| 章 | 内容 | 前置阶梯 |
|:--|:--|:--|
| PR | 输入、字符串与计算 | L01–L05、L09 |
| AR | 数组与记录 | L06、L08 |
| FL | 文本文件与异常处理 | L07、L09 |
| SR | 查找与排序 | L06、L11 |
| RC | 递归 | L04、L11 |
| SQ | 栈与队列 | L08 |
| LT | 链表、二叉树与哈希表 | L10、L11 |
| OP | 面向对象编程 | L12 |
| MP | 主程序与测试证据 | L04、L09，并结合相应结构 |

全册的体系为 9 章、36 型，章序就是建议的学习顺序：PR → AR → FL → SR → RC → SQ → LT → OP → MP（MP 章的 MP-01、MP-03 在第一道练习时就地学，因为每道大题都有主程序和截图）。每章先讲核心思想和题型树，再分卡讲解，章末比较易混处；另有每章的“伪代码 ↔ Python 对照与模板”。P4 与 P3 同考 19–20 节：P3 用伪代码笔答同样的算法（CT、FP 章），两边可以挨着学。

### 一张卡怎样读

1. **考法、识别信号**：从英文题干认出算法与数据去向，先分清“返回”“输出”“写文件”。
2. **解题思路、Python 模板**：学会从空文件组织声明、模块、控制结构与入口。模板里的大小、指针初值、参数不能机械搬到另一题。
3. **得分表述**：3–6 条带题号的 MS 原句，告诉你 MS 怎样描述这些动作。引用是检索入口；不是其他题的给分依据。
4. **得分点地图**：按核验语料的主题型独立行统计技能覆盖，不把副题型或同一行重复标签累加。s26 只进统计；行数不是分数，也不是命中概率。
5. **代表题精讲**：读规格 → 整题可运行程序 → 当前小问的逐点对齐 → 证据格 → 直观。完整程序保留其他小问，帮助你看见这一模块如何接入主程序；证据文档仍按各小问分格交。
6. **对应练习、前置阶梯、下一道变式**：在自己作答目录从头写，跑练习并按同题 MS 人工核对。变式改变一个主要条件，检验能否迁移。

第一次学先读精讲，不用猜代表题答案。做变式时先独立完成，再看 MS；程序测试通过后，还要检查模块头、类型注释、指定算法和证据格等人工项目。没有练习文件夹时可以手动运行，但按 D3 只能记“学习中”，不能仅凭一次示例输出标为掌握。

### 学习与练习的位置

卡片中的 `practice/p4/<卷>_q<题号>/` 是整道大题的练习目录：共 54 道（2022–2025 的全部核验卷；与 `_41` 整卷相同的 `_43` 卷不另做；s26 留作模考、2021 扩展卷没有练习，只能手动运行核对）。学生作答在 `attempts/<同路径>/solution.py`，不覆盖参考解。练习中的数据文件来自官方源文件的副本；程序用题给相对文件名，如 Trees.txt，不把本机绝对路径写进答案。

每次练习按“指定数据运行 + 同题 MS 逐点人工核对”记录结果。某次运行没报错，只能说明这条路径跑通；队列满空、数组边界、缺文件、递归终止等还需按该题要求检查。发现手册错误记入 `handoff/勘误.md`，不在学习会话修改建设产物。

## P4 通用得分规则

以下是准备答案时的检查方法；每条以一题 MS 作例，不能替代当前题自己的计分清单。

### 1. 先看独立点，再看上限与必有项

「1 mark each to max 7」⟦9618_s25_41:2(a)⟧ 的 8 个列点最多计 7 分。另一些题是分组上限：⟦9618_s24_41:2(b)⟧ 的异常处理必有 1 分，其余清单最多 6 分；不能把它理解成 8 点任取 7 点。

完整程序要覆盖全部要求；逐点核对时，`//` 按替代说法处理。MS 的示例只是实现方式之一，自己的写法满足同题得分描述也可以；但题目指定伪代码结构时要保留该结构。

### 2. 模块头、参数和缩进都是答案的一部分

「Procedure header (and end where appropriate)」⟦9618_s24_41:1(d)(i)⟧。在 Python 中写 `def`、准确的参数和缩进块；“and end where appropriate”不是要求在 Python 末尾写 ENDPROCEDURE。模块名、大小写、文件名照题目，参数个数与顺序要在定义和调用间保持一致。

题目分开考函数体和调用时也分开交：只写函数没有调用，并不能证明主程序已经用了它。返回数组后要接住返回值：「… and storing/using return value」⟦9618_s25_41:2(e)(i)⟧。

### 3. 声明要有真实结构，类型和大小写进注释

「… containing a 1D array of (100) integers QueueArray」⟦9618_w24_42:2(a)⟧。按 D10，题给 100 个整数就建出 100 个元素的真实 list，并注释类型与个数；只写注释或空 list 不能作为固定数组模板。二维数组的每一行、记录数组的每个对象要独立创建，不能用重复引用代替。

类题还会检查属性：「All 5 attributes declared as private with correct identifiers and data types」⟦9618_s24_41:2(a)(i)⟧。Python 按题目要求用注释声明类型，私有属性用相应写法创建。记录题是否需要私有，以当前 QP 为准。

### 4. 指针初值与“指向什么”按题干

「Queue field/attribute head pointer initialised to –1, tail pointer to 0」⟦9618_w24_42:2(b)⟧。先写清 head 指向首项、tail 指向最后一项还是下一个空位，再写满空判断与更新。不能把另一题的 0 / −1 约定搬来，不能用 Python 的负下标掩盖错误指针。

这题遍历的终点是「Starting at HeadPointer and incrementing until TailPointer – 1」⟦9618_w24_42:2(d)⟧；另一题若 tail 指向最后一项，边界就不同（D10）。

### 5. 给定算法按结构翻译；自己写时处理边界

「Remainder of function correct with nothing extra i.e. totalling, must match structure of given algorithm」⟦9618_w23_41:1(a)(i)⟧。先对应每句的状态和动作，再改成 Python：`DIV` 用 `//`，含终点的 FOR 转成不含终点的 range，MID 的起点按题目说明核对。

如果原伪代码或范例存在已核实的缺陷，卡片会注明具体原页和差异。按 D31 / D44：照 MS 说明填空得分；自己的完整程序按题意处理边界。不要把错误范例扩展成通用模板。自写伪代码按指南使用带界全局数组（D24），数组访问放在边界检查之后，不依赖 AND 短路（D25）。

### 6. 指定算法必须展示算法本身

「… comparing elements and swapping into ascending order」⟦9618_w25_42:2(c)⟧。写冒泡就写比较与交换；写插入就写暂存、移位与插入；写递归就有递归调用与基本情况。按 D10，不用 `sort()`、`sorted()`、`index()`、`count()`、`in`、`max()` 等代劳题目要求的算法。

这是针对所考算法的限制，不是禁止所有库函数。题目没禁止时，文件字段可 split；字符可逐个比较；`for I in range(...)` 中的 in 是循环语法。每次仍先看 QP 有没有明确的禁用要求。

### 7. 文件打开、关闭、异常是一组动作

「Opening the file (to read) and closing the file in an appropriate place」⟦9618_s25_41:2(a)⟧。打开正确模式，按 EOF 或题给组数读取；去换行、转类型、存进指定结构，再关闭。with 可以管理关闭，放在 try 内就同时覆盖打开失败。

「Exception try, catch with appropriate output. All file access within try」⟦9618_s25_43:1(d)⟧。只在数据读完后写一个空 except，或在 try 外访问尚未打开的文件变量，不能满足这个要求。追加与覆盖也要分清；`write()` 不自动补换行。

### 8. input、return、print、文件写出各有去向

「Returning the calculated count value」⟦9618_s23_41:1(c)⟧。函数要求 returns 就 return，由主程序决定是否输出；print 不会把结果交回调用者，write 则把内容送进文件。

输入提示要与读入一起写：「Prompt to enter filename and reading input」⟦9618_s25_41:2(a)⟧。本系统提示放在 `input("...")` 内（D13）；自动测试不把提示算作独立输出行。题给具体输出格式时按格式，没规定的提示措辞不要自行升级为额外扣分条件。

### 9. 每个截图格按自己的 MS 核对

「Prompt and input of filename TheData.txt」⟦9618_s25_41:2(e)(ii)⟧ 不只是程序最终输出正确，还要看到输入。文件证据则是「Screenshot of data in red file. Filename must be shown in same screenshot as data」⟦9618_s25_41:2(e)(ii)⟧：打开真正写出的 Red.txt，内容和文件名同时可见。

随机题按要求检查“同批数据排序前后、边界查找结果”，不要求和 MS 示例抽到相同的数。代码格贴代码，截图格贴运行证据；不同阶段各留一份，不能用最后一次运行覆盖先前要求的无效输入测试。

### 10. 递归的两条非空分支都要传回答案

「… if match return recursive call adding 1」⟦9618_w25_43:3(a)(i)⟧ 与「… if no match return recursive call without adding 1」⟦9618_w25_43:3(a)(i)⟧ 分别给分。先判基本情况，再访问首项；参数要朝终止条件缩小，递归结果要 return，而不只是调用。能输出一次正确结果还不足以证明空输入、未命中与终止路径正确。
