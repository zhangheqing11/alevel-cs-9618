# CIE 9618 Paper 3 · Advanced Theory 题型手册

> 2027 年 5–6 月考季用。语料：2022–2026s 全部 variant（核验语料）+ 2021（扩展）。给分依据只认每题自己的 MS；本手册的英文得分句都逐字引自对应 MS，并标出题号。伪代码一律按 2027–29 版剑桥伪代码指南书写（与 P2 手册、阶梯各级对照卡一致）。

## 使用指南

### 这本手册怎么组织

- **9 章 79 个题型**，章序按考纲第 13–20 节排：DR 数据表示 → CI 通信与互联网技术 → HV 处理器、并行处理与虚拟机 → BL 布尔代数与逻辑电路 → SY 系统软件 → SC 安全 → AI 人工智能 → CT 计算思维与问题求解 → FP 进一步编程。
- P3 是 A2 的**笔答理论卷**，但不只是“背定义”：
  - **描述 / 解释题**占大头（HV、CI、SY、SC、AI 几乎全是），写法和 P1 一样——一个得分点一分。
  - **计算与作图题**有固定套路：浮点数换算（DR）、真值表、积之和、卡诺图与布尔代数化简（BL）、RPN 与栈（SY）、Dijkstra / A*（AI）、BNF 与语法图（SY）。
  - **写代码题**用伪代码：声明记录 / 集合 / 枚举类型（DR）、查找与排序、栈 / 队列 / 链表 / 二叉树（CT）、类定义、文件处理（FP），以及汇编（FP-02/03）和 Prolog 式声明式编程（FP-07～09）。这些题的写法与 P2 一脉相承。
- 每章开头是**核心思想**（这一章在解决什么问题、题型之间怎么连）和**题型树**（每型的星级、小问数、分值）；章末是**本章易混辨析**。
- 每个题型一张**题型卡**，固定 9 个部分；**写代码 / 类图题型**另加 3 个部分：

| 部分 | 作用 |
|:--|:--|
| 考情 | 构建器按语料自动统计：小问数、分值、出现卷数、设问分布、★ |
| 考法 | 这个题型怎么问、常见几种变化 |
| 识别信号 | 题干里能认出它的英文原词 |
| 解题思路 | 编号步骤，照着做就能写出得分答案 |
| **伪代码模板**（写代码类） | 这类题的标准骨架，按 2027–29 指南写法 |
| 得分表述 | 3–6 句最常出现、最能拿分的 MS 原句，可直接默写 |
| **得分点地图**（写代码类） | 按该型已拆分的 MS 得分点统计：哪几分几乎每次都有、对应哪个技能标签 |
| 易错与失分 | 来自 MS 的限定、常见混淆，以及考官报告指出的失分 |
| 代表题精讲 | 一道 2022–25 的典型题：在考什么 → 完整作答 → 与 MS 逐点对齐 → 英文作答句 / 规范代码 → 直观 |
| **同题 Python 版要点 / 阶梯衔接**（写代码类） | 同题的 Python 写法与伪代码的不对应之处，以及要先过的阶梯级与练习（P4 也考同样的算法） |
| 下一道变式 | 同型、换了一个特征的另一题，自己做 |
| 刷题清单 | 构建器自动列出该型全部真题，新卷在前；2021 扩展单列 |

- 写代码类题型是：DR-03、DR-05、CT-02、CT-03、CT-06、CT-07、FP-06、FP-10，以及作答为代码时的 CT-08、CT-09、FP-05。汇编（FP-02/03）、Prolog（FP-07～09）、BNF / 语法图（SY-07～09）、逻辑电路与卡诺图（BL）按理论卡写，但卡里给**逐步作答模板**。
- 另有一份**核心概念表**（`P3核心概念`）：每章的术语按“英文得分句 / 中文定义 / 直观理解”三层列出。英文列带题号的是 MS 原句；标“非 MS 原句”的是标准定义，用于理解与默写。

### 记号

- **题号**写成短格式：`s24/31 Q6(a)` = 2024 年 6 月考季、Paper 3 第 1 套（variant 1）、第 6 题 (a)。季：`s` = 5–6 月，`w` = 10–11 月。
- **“英文句” + 题号**：逐字引自该题 MS 的句子（校验器逐字核对过）。
- **MP n**：该题 MS 计分清单的第 n 个得分点（Mark Point）。语料拆分的顺序个别地方与 MS 印的编号不同，卡里遇到时会列出对照。
- **技能标签**（如 `user-defined-type`、`random-file`）：写代码题得分点考的那项技能。词表 `papers/p3/skill_tags.json` 在 P2 词表上扩充（同一套标签，学习记录跨 P2 / P3 / P4 统计失分）。
- **布尔代数**：`.` = AND，`+` = OR，字母上加横线 = NOT。本手册用 A̅ 表示 NOT A；盖住整个式子的长横线在纯文本里写成 NOT(…)，卷面上照原样画长横线。MS 抽取文本里的横线全部丢失，BL 章的表达式都是看原页写的。
- **“讲解时请对照原卷 QP p.N”**：这道题要看图、表或作答框才能讲清，学习时打开原卷第 N 页。
- **★ 星级**由构建器按出现频率与分值算出，★★★ 为几乎每季必考。
- **2026 年 6 月的 12 份卷**（`s26`）留给考前限时整卷模考：专项刷题时跳过；手册的代表题与变式也避开了它们。

### 先过哪一级阶梯

P3 的写代码题要用伪代码手写，但先在 Python 里把同样的逻辑写对、测过，伪代码会稳得多（P4 也考同样的算法）。题型与阶梯级的衔接：

| 阶梯级 | 学完可以开的 P3 题型 |
|:--|:--|
| L06 数组、线性查找、冒泡排序（E02、E03） | CT-01、CT-02 线性查找部分、CT-03 冒泡排序部分 |
| L07 文本文件 | FP-10 文本文件部分 |
| L08 记录、栈与队列（E01、E03、E04） | DR-03、DR-04 记录；CT-06 栈；CT-07 队列 |
| L09 异常与输入验证 | FP-11 异常处理 |
| L10 链表与二叉树（E01–E05） | CT-08 链表；CT-09 二叉树 |
| L11 递归、二分查找、插入排序（E01–E05） | CT-02 二分查找、CT-03 插入排序、CT-04 大 O、CT-10～CT-12 递归 |
| L12 OOP | FP-04～FP-06 |

其余题型（DR 的浮点数与文件组织、CI、HV、BL、SY、SC、AI，以及 FP-01～03、FP-07～09）不依赖阶梯，随时可学。FP-10 的随机文件（`SEEK`、`GETRECORD`、`PUTRECORD`）在阶梯里是 L09 的选学内容，没有专门练习，按卡里的模板学。

### 推荐用法

1. **首学一个题型**：读卡的“考法 → 识别信号 → 解题思路”（写代码类再看伪代码模板），再看代表题精讲（直接看讲解，不必先做）。
2. **自己做“下一道变式”**：文字题用英文作答；计算、作图题写出全部过程；写代码题手写伪代码、计时。按该题 MS 逐点自批，把丢分的那个词或得分点（以及技能标签）记下来。
3. **刷题**：从刷题清单里由新到旧取没做过的题；每次批改都对照 MS 原文。
4. **默写**：“得分表述”和核心概念表的英文列是定义题、解释题的标准句；BL 的定律表、DR 的浮点换算步骤、AI 的 Dijkstra 步骤要能默写出来。
5. 发现卡片里的错误或 MS 引文问题，记到 `handoff/勘误.md`，由总控修正。

- **试卷**：1 小时 30 分钟，75 分；考纲第 13–20 节；全部题目必答；全部笔答；**禁用计算器**——浮点数换算、补码、卡诺图都要手算并写出过程。占 A Level 总成绩 25%。

## 通用得分规则

以下规则从 MS 的写法归纳而来，适用于全卷。每条都附了一处 MS 原文作例子；具体某题的给分永远以那题自己的 MS 为准。

### 1. 一个得分点一分，点数要够

描述、解释题的 MS 几乎都是“列出可得分点，每点 1 分，封顶 n 分”：「One mark per mark point (Max 3)」⟦9618_s23_31:8⟧。所以：

- 分值 = 需要写出的**独立**得分点数。3 分题写 3 个不同的点，最好多写一个作保险。
- 同一个意思换说法写两遍只算一分。
- MS 里以 `…` 开头的点是**前一点的展开**，要和前一点一起写才成立：先写“A large number of computer processors … connected together”，再写「… simultaneously performing a set of coordinated computations // collaborative processing」⟦9618_s23_31:8⟧。

### 2. 读懂 MS 的记号

| 记号 | 含义 |
|:--|:--|
| `/` | 同一得分点里可以互换的词（`processors / separate computers`） |
| `//` | 同一得分点的另一种写法，任写其一，**不能累计两分** |
| `( )` | 括号里的内容不要求，只提供语境 |
| `…` | 接着上一点说的展开点 |
| `Max n` | 本组最多给 n 分；分组的题（如“好处 Max 2、局限 Max 2”）每组都要写够 |
| `MP n` | 计分清单第 n 点 |
| `Example answer(s)` | 范例，列出的不是唯一写法；给分看上面的计分清单 |

例：「Records are stored one after the other as they are collected // records are stored in chronological order」⟦9618_w24_32:2(a)⟧——两种说法是同一分。

### 3. 只问一样就只写一样，问区别才成对写

“Describe the features of a RISC processor”只写 RISC 自己**有什么**，不拿 CISC 来比、不写“RISC 没有 …”——考官报告多次指出这样写拿不到分（见 HV-01 卡）。问 differences / compare 时才成对写：「RISC has fewer instructions // CISC has more instructions」⟦9618_s22_31:4(b)⟧。同理，问 virtual machine 不要答 virtual memory，问 SIMD 不要答 MIMD。

### 4. 计算、换算题：过程分与答案分分开

浮点数、补码、真值表等题，MS 普遍把过程单列为得分点：「correct exponent with associated working」⟦9618_s23_32:1(a)⟧，「One mark for working, all four columns P, Q, R and S」⟦9618_s24_31:6(a)⟧。

- 题目写了 Show your working 就一定写过程，中间结果写在 Working space 里；答案错了，过程仍可能得分。
- 二进制答案按题目给的位数写满（尾数、指数各几位）；浮点数题先判断正负、再移小数点。

### 5. 填表、填图题：按块或按错误数给分

真值表按行块给分（「One mark for first four rows of column Z」⟦9618_s24_31:6(a)⟧），卡诺图按错误数给分：「Two marks if no errors present」⟦9618_s23_31:7(a)⟧、「One mark if one error present」⟦9618_s23_31:7(a)⟧。每一格都要填（卡诺图的 0 也要写），每一块都值得检查。

### 6. 写代码题：按计分清单给分，只写伪代码

P3 的类型声明、ADT、类、文件处理题与 P2 一样：MS 先给范例，再给计分清单，**给分只看清单**。

- 关键字与结构要完整：「TYPE Booking and ENDTYPE correct」⟦9618_s25_31:1(b)⟧；每个字段都要按指南写声明：「Declare used correctly for every field in the response」⟦9618_s25_31:1(b)⟧。
- 题目给的类型名、字段名、类名照抄；题目前一问定义的类型，后一问要用上：「DECLARE AircraftType as Aircraft (correct data type from part 4(a))」⟦9618_w22_32:4(b)⟧。
- 只写伪代码，不混 Python 语法或插页以外的语言函数（决策 D2，P2 手册通用规则 4 的对照表同样适用）；不依赖 `AND` 短路（决策 D25），链表、二叉树遍历用标志变量或分层判断。
- 汇编题只用题目给的指令集；Prolog 式子句照题目给的谓词名与参数顺序写。

### 7. 描述算法与过程：按步骤顺序写，每步一个动作

RPN 求值、Dijkstra、A*、中断处理、流水线、数字签名这类“过程题”，MS 按步骤给分，步骤之间有先后。按顺序写，每句只说一个动作并点名操作对象：「PUSH result back onto stack」⟦9618_s22_31:5(b)(ii)⟧，而不是笼统地说“用栈来算”。

### 8. 画图：结构齐全、连线正确、标注完整

语法图、逻辑电路、类图按“该有的都有、连线正确、标注齐全”给分：「correct structure – name, boxes and arrows (in and out).」⟦9618_s23_31:6(c)⟧；「Correct connections between logic gates」⟦9618_w22_32:8(a)⟧。题目让标的输入、名称、多重性都要标。

### 9. 用精确的术语，保留限定词

定义里的限定词逐个保留，少一个常常整点不给：「A (user-defined non-composite) data type with an ordered list of possible values」⟦9618_w22_31:3(a)⟧——“ordered list”不能省。写机制而不是形容词：“the hash value gives the address of the record”，而不是“it finds the record quickly”。

### 10. 有情境就扣情境

题目给了具体情境（某个网络、某个程序、某张表），答案要说**这个情境**里的东西：用题目里的结点名、类名、字段名、数值来写，而不是只背通用定义。
