## 接口约定

- 全部固定长度数组建成真实 list，英文注释写明大小与类型。主程序在 __main__ 入口下，导入不触发 input。
- 标识符与指针初值依题目：尤其 w25_43 的 QueueTail 指最后一格，其他线性队列通常指下一空位，不能套用统一模板。
- w22_42 未命名递归函数用 MS 的 RecursiveOutput(Start)，Start 按最后有效下标传入；与 QP 迭代版本的尾后参数做一位换算。
- w23_41 RecordData 可用公开字段或 MS getter；w24_42 记录队列兼容 Headpointer/HeadPointer 和标量/二元组返回；初始化位置不强制写在构造方法。
- 随机数通过 seed 包装或调用观察确定预期，不硬编码随机序列。脚本提示语和说明文字按行内结果匹配，具体措辞不作额外要求。
- files 型函数测试用 testkit.use_files；脚本用 run_script，所有生成文件位于临时目录。Tree.txt 由程序生成，不作为源文件复制。
