## 接口与边界

- 各题接口见 task.md；QP 未命名的过程使用该题 MS 的名字。主程序只在 `__main__` 入口执行，声明和方法头不预写进 starter.py。
- 数组建立真实 list，属性 / 数组类型用英文注释；私有属性只在 QP 要求时检查。继承接受 super() 或显式父类调用。
- 函数读数据文件用 use_files；主程序用 run_script，少数测试用 runpy 取得主程序对象或跟踪到文件读取阶段结束，不依赖 sources/ 存在。
- 提示语不固定；QP 给出明确输出格式时按格式测，截图格核对该题 MS 列出的值。浮点工资接受原值的浮点显示差异。
- 不通过内置算法代劳的要求按 D10 ③ 人工检查（D42 ④ 暂缓共享内置函数检查器）。
- ChooseCard 的选择记录实现不限；对象可存于变量或容器，测试不强制与 MS 相同的局部变量名。
- 每题用例运行均小于 5 秒；每个参考解全过，每个 mutant 都有真实断言失败（非收集错误）。

## 按 QP 处理的差异及 MS 范例修正

- 9618_s22_41_q2：接口：`Balloon(DefenceItem, Colour)`、`GetDefenceItem()`、`ChangeHealth(Change)`、`CheckHealth()`、`Defend(MyBalloon)`。MS p.25 原页 Python 把 `ChangeHealth` 印成 `VhangeHealth`，参考解修正为题干方法名。提示语和状态文字不固定；测试只要求输出盾牌名称及状态行，人工核对该状态表示仍有生命值。主程序接收返回对象的赋值与 Balloon1 名称人工补核。2(f) 有 10 个可选点最多 8 分，按比例折算。
- 9618_s22_42_q3：接口取 QP 的 `ChooseCard()`（大写 C），参考解用 MS 的 `NumbersChosen` 保存 30 个 BOOLEAN，学生可用任何合适的选择记录方式；返回 0–29 下标。`CardArray` 与 `Player1` 在主程序建立，测试运行完整入口后读取这两个数组。MS p.32 的 `chooseCard` / `true` / `NumbersChosen(...)` 分别修为 `ChooseCard` / `True` / 方括号下标；p.29 的 `File.close` 改为 `with` 自动关闭，去掉颜色行的换行。MS p.35 测试 2 将 white 误写为 while，按 QP 数据文件输出 white。输出可为“数字 颜色”或“颜色 数字”，同一张牌可分两行。3(c) 10 个可选点最多 7 分，3(d) 9 个可选点最多 6 分。缺文件测试在读取阶段后停止，避免对 QP 未规定的后续选择作要求。
- 9618_s23_41_q2：接口采用 QP 的 Vehicle / Helicopter 方法名，2(c) 未命名输出过程采用 MS 的对象方法 `OutputCurrentPosition()`（父、子类各一份）。`Helicopter(ID, MaxSpeed, IncreaseAmount, VerticalChange, MaxHeight)`；允许 `super()` 或显式父类调用。MS p.21 高度越界时写 `MaxHeight`，漏了 `self.__`；参考解修正为 `self.__MaxHeight`，并测试越过最大高度。MS 构造方法漏写 HorizontalPosition 的类型，补 INTEGER 注释。QP 类图的 `GetVerticalPosition()` 同时实现；它未有独立计分小问。截图只断言 MS p.25 的 60、40、120、80、6，提示文字人工核对。
- 9618_s23_42_q3：构造参数采用 MS：`Employee(EmpNum, Pay, Job)` 与 `Manager(EmpNum, Pay, Job, Bonus)`。全局 `EmployeeArray` 为 8 个对象的 list；`EnterHours()` 无参数。周编号 1–52 映射 0–51，不测试 QP 未定义的无效周。MS p.35 / p.36 将 EmployeeArray 写成 Employees，p.36 `for(Y in range(0,8):` 是语法笔误；统一修正，输入 ID 保持 STRING、去行尾，完整读取工时对并关闭文件。p.29 的百分比公式照原页实现。p.37 截图顺序跟工时文件不同于 EmployeeArray；QP 未规定输出顺序，自动测核对全部 ID/总额映射，接受浮点显示差异，不强制排序。文件开关位置及调用结构人工补核。3(c) 8 个可选点最多 7 分，3(d) 6 个可选点最多 4 分。
- 9618_s24_41_q2：接口照 QP：`Tree(Name, Growth, MaxHeight, MaxWidth, Evergreen)`、`ReadData()` 返回对象列表、`PrintTrees(Item)`、`ChooseTree(Trees)`。QP 2(e)(iii) 写 ChooseTrees（多 s），与前文不一致，按定义用 ChooseTree。输入次序采用 MS p.25：先 keep/lose、再最大高、再最大宽、选树名、购买高度。仅测试已声明的 keep/lose；不要求其他同义输入。空匹配时输出消息后结束，不进入 MS p.27 没有保护的无限购买循环。年数不强制取整；官方截图接受 3 / 3.75 / 4，Beech 示例接受 12。PrintTrees 按 QP 文字格式，末尾句号不影响判定。MS ReadData 用 split("\n")，遇文件末尾换行会产生空记录，参考解逐行读取；官方原件字节不变。
- 9618_s24_42_q2：接口照 QP 的 `Node(Data)`、`TreeClass()` 及 get/set/InsertNode/OutputTree 名称。MS 2(a)(i) 得分点称属性 public，但 Python 范例为私有；测试接受公有或私有，只按 getter/setter 行为与题给指针约定核对。MS p.23 原页的 NumberNodes 增量实际在左右分支之外（抽文本会丢缩进），参考解保持。该算法对重复值 / 满树行为 QP 未定义，测试只插入不同整数且不超过 20 个，不额外规定溢出返回值。2(b)(ii) 7 个可选点最多 6 分。无数据文件，不复制本卷其他题的文件。
- 9618_s25_41_q3：接口照 QP 的 Node / Tree、get/set、Insert、全局递归过程 `OutputInOrder(RootNode)`；null 用 None，不用整数下标。构造 Tree 时已有根对象，不额外规定空树构造。QP 明确相等值走右，所以包含重复值插入测试。Insert 可迭代或递归；OutputInOrder 必须递归，测试包装全局过程统计非空结点调用次数。MS p.31 的属性及 __init__ 下划线在抽文本中丢失，已看原页后照正确 Python 写法转写；没有据抽取乱码认定官方笔误。无数据文件。
- 9618_s25_42_q3：接口照 QP：`Animal(Name,Sound,Size,Intelligence)`、`Parrot(...,WingSpan,NumberWords)`、`Wolf(...,TerritorySize)`、`Description()` 返回字符串。`SetTerritorySize(Change)` 虽叫 Set，QP 类图和 MS 都要求“加上参数”，负参数用于减少。MS p.42 Wolf.Description 的领地句写成 it's territory，缺少 QP 指定的句号与 Its；按 QP p.11 的完整句式修正为“. Its territory is … square miles.”。其他长字符串在 PDF 里跨行，参考解用合法的分段拼接。此题没有私有属性要求，照 MS 用公有属性，不强制学生改成私有。不测试 1–10 以外的 size/intelligence，QP 未要求校验。
- 9618_s25_43_q3：接口照 QP：`Node(Data)`、`LinkedList()`、`InsertNode(integer)`、`Traverse()` 返回空格分隔字符串、`RemoveNode(integer)` 返回真正的 BOOLEAN。末尾多一个空格按 MS 范例接受，内部整数间一个空格。MS p.41 Python 在尾结点访问 NextNode.GetData 会遇 None，且非头删除与找不到时没有返回 BOOLEAN；按 QP 修正为先查下一结点是否非空，再分别返回 True / False。MS p.44 只保存两次 Traverse 返回值，没有 print；QP 截图格与 MS p.45 要求输出两组列表，所以参考解补输出。3(b)(iv) 7 个可选点最多 6 分。
