## 接口约定与兼容性

- 原题命名模块保留 GeneratePassword、FileToQueue、SaveStack、ValidateScore；未命名算法用 main() 包装。原题未给的文件名、字段长度、数组名/容量和输出格式均在每题“Python接口”写明，仅用于Python测试，不作为原卷的新评分要求。
- 1起数组映射为同大小真实list，下标减1；未给下界时明确所选约定，不伪称官方下界。链表沿用批2：List[1..200]对应题给指针，另有0号占位，null=0。CheckTotal原本0起，保持0–35。SameMonth仅提供足以容纳原图4–6号的示例容量，不强制题外容量。
- 队列 AddToQueue 为已有模块，FileToQueue测试替换它，核对逐行输入与满队列终止；不重新考队列ADT实现。GetStat/Reset、GetAverage/Update、DAYINDEX、RandomChar/Exists亦为已有模块或插页函数。
- 文件测试在临时目录运行，核对源文件、输出文件、覆盖/追加模式以及关闭句柄；保留空行和字段内空格，不把空行当EOF。仅用watch_open跟踪本次调用并保留句柄，避免垃圾回收掩盖漏关文件。
- 输出题在题面列明纯输出行与顺序；LastLines直接比较splitlines以保留空行，其余output_lines忽略空行/行末空格。输入提示使用input(prompt)，不额外print。数值允许等值表示。
- 随机密码用可注入RandomChar，检查合法字符、三组四字符、连接符与全局去重，不固定输出、不要求某个字符必须出现。最大值和三次比较累加另查D10禁用的内置算法捷径；其余MS对实现步骤的要求人工核对，不固定循环语句或内部变量名。
- 同题MS有多方案时兼容正确替代实现；SaveStack接受POP和直接读栈顶两套方案，不强制调用POP、不强制原栈被清空。输入前提不足的边界不扩展测试。
