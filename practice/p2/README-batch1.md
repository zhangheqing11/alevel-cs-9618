## 统一接口

- 使用题目的模块名、大小写和参数顺序；无模块名的算法由 Python main() 包装，伪代码不额外添加原题未要求的模块头。
- BYREF 的标量参数使用单元素 list；日期用 datetime.date。TODAY 与既有模块为可替换的提供接口。
- 有效输入域照题目；未要求的参数验证不作为自动测试要求。随机数固定种子，只检查范围、性质及输出行为；已有模块用测试替身提供确定数据。
- Timer 的 Python 环境通过 ReadTick() 提供外部 Tick，避免真实等待；伪代码仍直接读取全局 Tick，保持原题要求。
- 伪代码语法、声明、过程调用形式、算法结构要求由每题末尾清单人工批改。测试只访问公开接口与题给全局量。

## 原题边界与需要总控决定

- **需要总控决定：9618_s24_22:6(a)**。MS p9 的示例先将每个词删到其前空格，最后才删除空格。前缀恰好 13 字符时会多删单词，甚至删空后越界。参考解遵循 QP p12 的“小于 14 字符”规则，每次同时删除前置空格；测试覆盖 `abcdefghijklm longword → abcdefghijklm...`。未改 MS 或 corpus。
- **需要总控决定：9618_s24_22:8(b)**。QP 要求移除行首空格，故全空格行返回空串。MS p11 的 NumSpaces 算法只在遇到非空格时设值，此边界原样返回。参考解按 QP 补齐；请确认人工批改口径。
- s25/23:7(a)(i) 参数按 QP 表的积分、日期排列；MS 示例相反。w25/22:6 参数按 QP 示例表排列为 String1, String2, CaseMatters, Position，与 MS 一致；QP 前文说明顺序不同。
- w23/21:6(a) 溢出与 EOL 同时发生时严格按本题 MS 分支：输出旧缓冲，保存新串，EOL 在非溢出分支才处理；题面接口中已明确此口径。
- w24/21:4(c) MS 接受任一参数作除数；本练习调用约定按 QP 的 x / y 公式，第一参数为分子。
- Timer 自动测至少 30 秒的时限；原题没有规定短于 30 秒时“提前 30 秒提醒”的处理方式。
- D26 字形仅在题面转写时按原页规范；没有修改原始语料。

- 已同步 D30：w23/21:6(a) 的普通赋值 MP5 使用 assign-value；MP8 清空缓冲仍属于 initialise-variables。原始标注真源的回填由 codex-1 负责，本任务只更新练习技能。
