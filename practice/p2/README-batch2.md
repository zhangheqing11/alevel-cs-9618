## 统一接口与核对口径

- 保留题目的模块名、记录字段与参数顺序。原题没有模块名的算法，用 Python main() 包装，answer.pseudo 不私加模块头；TYPE 题用同名 Python 类，构造参数依表顺序，类型声明人工检查。
- 1 起数组通常采用同样大小的真实 list，注释写 Python 下标 = QP 下标−1。链表 List 用第 0 项占位，保留 QP 指针值 1–200、null=0；没有把 null 误换成 -1。Check/CheckTotal 原本 0 起，不换算。不用题面没有的映射容器替代数组。
- QP 未给总容量的 ModInfo / Result，只提供足够容量的真实 list；接口明确容量仅为样例，不强制 100。原有模块、记录类型、数组在 starter 的 provided 部分；学生不需要重写这些模块。Encrypt/Decrypt、传输/接收等提供可替换的示范接口，不连接网络。
- 文件测试通过 candidate_path 选择候选，再在临时目录加载；读题的样例在 files/，格式遵循 QP，每个 task.md 注明最后一行是否换行。写题检查生成文件完整内容、覆盖/追加模式与源文件保持；逐行 WRITEFILE 对应 LF 结束。
- 文件句柄检查同时跟踪 open 与 Path.open 并保留引用，避免遗漏 CLOSE 被垃圾回收掩盖。每次调用后检查已关闭。CreateFiles 是纯写题，无输入文件；ReceiveFile 由 GetData 输入，不虚构官方数据文件。
- 查找与排序题另作题目明令要求检查：用 AST 检查 membership in/not in、sort/sorted、index、max/min 等被禁止的替代操作。它不指定循环写法、变量名或内部数据流；其他断言检查公开行为与题给全局数组。冒泡标志、缩短边界、伪代码语法仍在人工清单核对。
- 随机题使用可注入 RAND，固定随机源，仅检查可选项、不同馅料及输出性质，不要求某次抽取或固定调用顺序。数组与记录的全部末项、配对移动、空位判断、状态更新均有行为测试；同值排序稳定性、QP 未定义的输入验证不额外要求。
- output_lines 会忽略空行及行末空格，因此每题接口明确有效输出行与格式；LastLines 需要保留空行，直接用 splitlines() 核对。input 提示使用 input(prompt)，不另 print（D13）。MS 示例精确文字在接口有明确说明；浮点平均数接受等值表示。
