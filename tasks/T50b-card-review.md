## 可以优化的方向（按你判断的价值排序去做，不必全做）

1. **心智模型与知识主线**：各章「核心思想」——把一章讲成一个能自己推出题型的模型，而不是题型清单；写一份跨卷「概念主线」（如 数组 → 记录 → 栈 / 队列 → 链表 / 树 → 类；表示 → 硬件 → 系统软件 → 安全；伪代码 ↔ Python ↔ P4 上机），说清每一步新增了什么、旧知识怎样迁移。放在 `docs/guide/` 或各卷 front / back。
2. **★★★ 题型卡的讲解层**：「解题思路」「直观」「易错」「迁移」——更好的类比与反例、学生最可能卡住的那一步、考官的出题逻辑、同型题怎样一眼认出、从代表题到变式真正要迁移的东西。**不动**得分表述的 MS 引文、代表题 / 变式的选题与 MP 对齐表。
3. **考场作答方法**：每卷一页「怎样把会的写成分」——命令词到答案结构的映射、拿分句式、时间分配、写代码大题的得分链、常见“会但丢分”的模式；用真题行做例子。
4. **教学 skill 的讲解与诊断能力**：`references/few-shots.md` 与讲解相关的说明——更好的诊断式提问（找到学生缺的那一环）、误区探针、检索练习与间隔复习的提示、把错误转成下一道题的方法。**不改** D47 七条协议与 SKILL.md 的硬规则（证据、门槛、写入边界）。
5. 任何你认为能明显提升学习效果的其他优化。
