# T51 · 开场检索题库

## 目标

T50b 给教学 skill 加了「把错误转成下一道题」与「开场检索」（`references/few-shots.md` 示例 6–8、`theory.md` 开场检索段）：每次课开场做 2–3 道 30 秒小题，只测上次缺的那一环。现在这些题要导师每次现编，质量与证据都不稳定。本任务建一个**按题型码组织、答案有 MS 证据的检索题库**，再给一个抽题脚本，导师开场按学生「学习中」的题型直接抽。

## 产出

1. `skill/cie-9618-cs-tutor/references/retrieval/P1.md`、`P2.md`、`P3.md`、`P4.md`：每卷一个文件，按章、按题型码排列；格式严格照交接文档 §2（脚本要解析）。
   - 覆盖：**全部 ★★★ 题型每型 2 道**（66 型），**★★☆ 每型 1 道**（103 型）；★☆☆ 不做。
   - 每道题只测一环（优先取该卡「迁移与卡点」的「卡点」，或「易错」里最常丢的一分），30 秒能用英文答完（1–2 句，或不超过 3 行代码 / 伪代码）。★★★ 的两道里至少一道**换情境**（同一模型换到另一个设备 / 数据结构 / 场景），测迁移而不是背题。
   - 答案有证据：MS 原句一律写成「…」⟦行 id⟧（校验器逐字核对）；代码 / 伪代码答案标「非 MS 原文」并合伪代码指南 2027–29（P2 / P3）或 D10（P4）。
2. `skill/cie-9618-cs-tutor/references/retrieval/README.md`：题库的格式、怎样用（何时抽、抽几道、✗ 怎样处理）、怎样补题。
3. `skill/cie-9618-cs-tutor/scripts/retrieval.py`：`pick`（从记录表的「学习中」题型或指定题型抽题，默认只出题面）、`show`（看答案）、`check`（格式与覆盖自检）。细节见交接文档 §3。
4. 改 `references/few-shots.md`「把错误转成下一道题」、`references/theory.md`「开场检索」段、`references/handoff-template.md` 的检索待办行：**先从题库抽，题库没有的才现编**；现编的好题写进交接文档，留给总控收进题库。只改这几段的说法，不改协议（检索不改记录表、间隔 1 天 → 1 周 → 章末、连续两次答对才删）。

## 约束

- 证据规则（AGENTS.md §5）：给分说法只能来自该行 MS；答案引 MS 时**只用该题型卡的代表题 / 变式行或该章 `core/` 概念表里已有的句子**（学生首学时见过，不提前泄露复测用的题）；**不用 s26 行**（D1，模考预留）。
- 不写不带 ⟦⟧ 的「」（T50 M1 / 构建器正则）。
- 不改 `SKILL.md`（§1 的入口由总控在验收时加）、不改记录表、不改 D47 七条协议。
